# 严格规格书（STRICT_SPEC）— 以 Basement.md 原文为准的形式整改

> 本文件是 2026-11-06 形式整改的唯一依据。用户原话："要严格按照我描述的做软件！"
> 参考图1 = PCL2 启动器（大厅形式参考）；参考图2 = 工具箱 A1-A4 草图。
> 规则：与本文冲突的旧 UI 一律以本文为准；设计语言仍用玻璃拟态深色（用户已认可），但**结构与布局**必须严格照抄本规格。

## 0. 全局
- 保留：玻璃拟态材质、动效、深色主题（设计语言属主批准范围：新拟态/液态玻璃/玻璃拟态/云母/毛玻璃/陶瓷/纸张）。
- 所有新增文案简体中文；core/ 一律不改（数据不够找 lead）。

## 1. 大厅 HomeScreen（参考 PCL2，参考图1）
自上而下：
1. **右上角横排**：软件更新提醒（小圆点角标即可）· 通知（铃铛，点开抽屉列表）· **登录悬浮头像按钮**（圆头像，未登录显示默认人形图标）。
2. **问候区**（左上）：「您好，{昵称}」大标题 + 一行状态小字（未登录="点击右上角头像登录"，已登录="XX组织 · 欢迎回来"）。
3. **中央大视觉**：雷达同心圆 + 扫描线动画（液态玻璃质感，替代 PCL2 的大 logo 区）。
4. **底部胶囊抽屉**（参考图1 的「资源与下载/游戏抽屉」形式）：一个横向胶囊容器，内含并排两个大入口：
   - 左：**单人模式**（图标+文字，点击→新建走测任务页）
   - 右：**多人协同**（图标+文字，点击→多人模式入口页，见 §4）
   - 胶囊最左侧一个小齿轮（设置），最右侧小头像（同右上）。
5. 胶囊下方一张**宽卡片**（参考图1 modpack 卡）：显示最近一次会话（标题/样本数/时间），点击直接继续该任务；无历史时显示"围猎 v0.1 · 点击开始第一次走测"。
6. **登录页 + Profile 页**（点头像进入）：
   - 登录页：账号/密码输入 + 登录按钮 + 游客模式。本期本地校验（用户名≥4字符即可登录），字段存 weilie_prefs。
   - Profile 页：头像、昵称、所在组织（可编辑文本）、**登录记录**（时间+设备的本地列表，每次登录 append）、已登录设备（设备型号+androidId）。返回可回大厅。

## 2. 单人模式地图页 SingleMapScreen
### 2.1 顶部悬浮数据栏（原文：可自定义，分上半/下半）
- 玻璃卡悬浮在地图上方，**上下两半两个槽位**，默认：上半=追踪目标编号，下半=信号强度+信噪比。
- 槽位内容可点切换（弹选择表）：目标编号 / 信号强度(五格+文字) / 信噪比 / 邻区数 / WiFi数 / 坐标 / 采集时长 / 样本计数。
- 「整体显示」开关：合并为一整条。
- **专家/普通切换按钮**常驻数据栏右上角。
- 普通模式内容（原文 §普通模式）：运营商+制式（"中国移动 4G"）、当前基站已连接（编号可折叠）、五格信号条+强/中/弱/很弱（不显示dBm）、"附近还有 N 个基站"（点开列表）、切换时白话提示。
- 专家模式内容（原文 §专家模式）：毫秒时戳+时区、经纬度/来源/精度/海拔、LAC/TAC 与 CID/eNodeB/ECI/NCI 十进制+十六进制、MCC/MNC/运营商/制式/频段、dBm/RSSI/RSRP/RSRQ/SINR、邻区 6-8 个完整列表、WiFi 全字段（SSID/BSSID/RSSI/频率/信道/加密/厂商OUI）、小区变化轨迹 append-only 时间线。

### 2.2 左上角：地图图层按钮（原文 §左上方）
点开玻璃浮层，四项单选：
1. 普通地图（百度，见 §5）
2. 卫星地图（百度卫星图层）
3. 轨迹地图（Canvas 箭头轨迹叠加；**可导出** PNG）
4. 基站地图（开源基站位置图层；**可导出** PNG）——数据源暂用本地缓存站址点（若有），无数据显示提示。

### 2.3 左下角：工具箱悬浮按钮（参考图2 形式，原文 §左下角）
- 左下角一个圆形玻璃 FAB（扳手图标）。点击→**从底部弹出悬浮面板**，结构严格照参考图2：
  - 第一行：**A1**（圆形）+ **A2**（长圆角矩形）+ **A3**（圆形）
  - 第二行：**A4**（大圆角矩形，内部工具按钮网格，4列）
- **A1 = 设置/切换追踪基站**：弹浮层显示当前任务目标，可输入新编号切换（TaskInputParser）。
- **A2 = 自定义数据显示区**：默认上半=信息（当前小区摘要），下半=信号强度趋势迷你折线图（最近 60s RSRP）。点 A2 本体循环切换显示方案。
- **A3 = 切换专业/简单模式 + 拉人组队**：点击展开三个小按钮（专家/普通/组队）。组队=展开**行内**创建队伍/加入队伍两个选项（进入 §4 的房间管理页），不跳页。
- **A4 工具网格（10 项，原文顺序）**：点击后若功能简单→结果直接显示在 A4 区域内（A4 变成该功能的展示区，带返回）；复杂功能→弹新悬浮窗：
  1. 震动 开/关（简单，原地切换态）
  2. 切基站提醒 开/关（简单，原地切换态；开启时切基站触发震动+地图顶部悬浮通知）
  3. 信息采集（预留接口，A4 区显示"预留，后续填充"）
  4. 数据导出（复杂→浮窗：CSV/GeoJSON/KML/轨迹图 PNG + 分享）
  5. 定位与导航（复杂→浮窗：显示我的坐标+精度；"导航到目标"调系统地图 App 的 geo: intent）
  6. 帮助（复杂→浮窗：关于/说明书摘要/法律声明）
  7. AI 助手（打开 AiSheet 浮层）
  8. 拍照（复杂→浮窗：水印相机入口（系统相机+时间/坐标水印文字说明）、云上传说明位、**地图数字标点列表**：已拍标记 1/2/3…，可疑设备可选 emoji 特殊标记 📹；多人模式中队长可见队员标记）
  9. 实时信息（复杂→浮窗：即专家模式全量面板，含邻区/WiFi/变化轨迹）
  10. 设置（复杂→浮窗：配置/AI key/协同服务器地址/离线地图(占位)/权限检查与跳转/应用信息）
- **右下角自定义小组件区**：默认放 AI 悬浮按钮（原文 §功能4：AI 是右下角悬浮按钮）。
- **自由摆放（v0.2.4，用户口头追加需求）**：A4 内任一工具**长按 350ms** 即进入拖拽态——工具箱面板整体降为 alpha 0.35（150ms 动画），手指位置出现 44dp 幽灵钮跟随；松手即固定为该位置的悬浮圆钮（clamp 在安全区：顶部 ≥110dp、底部 ≥110dp、左右 ≥8dp），面板收起复原。已放置按钮：单击=执行该工具，长按=再次拖动改位置（重叠加 <56dp 时自动就近偏移）。拖拽进行中顶部中央出现半透明红底删除区，松手其上即移除。位置持久化于 `PREF_PLACED_TOOLS`（"TOOLID:x,y;…"，归一化 0..1，上限 6）；旧 `PREF_PINNED_TOOLS` 数据自动迁移为右侧竖排默认位并清除。AI/缩放±/定位为导航类固定钮，不参与拖拽。

## 3. 多人模式
### 3.1 入口（原文 §多人模式 两条进入路径）
- **从大厅进入**：先到「多人模式入口页」：两张大卡（创建队伍 / 加入队伍）。创建→**先选身份**（队长/队员/观战 三选一）→ 创建得到队伍码 → 进「房间管理页」。加入→输入 6 位队伍码 **或扫码**。
- **「出示二维码」按钮**：房间管理页给已加入的人展示队伍码二维码（纯本地生成，zxing-core 或自绘简易矩阵均可——**不新增大依赖**，可用自绘方块码简化版+纯文本队伍码复制按钮兜底）。
- **从单人模式进入**：A3 展开的"组队"点击后**按钮展开**（原地出现 创建/加入 两选项），点击后进入与从首页进入相同的界面（房间管理页）。
### 3.2 房间管理页
- 成员列表（含身份徽标）、队伍码+二维码出示按钮、聊天大厅（文字+图片；**对讲开关**：开=按住说话按钮占位，本期只做 UI 与状态）、「进入任务」大按钮 → 进协同地图（现 TeamRoomScreen 地图部分）。
### 3.3 协同地图页（原文 §进入多人模式之后）
- 布局同单人模式（数据栏/工具箱/图层全部保留）。
- **右侧上部两个悬浮钮**：「任务」（当前任务+队长下发指令列表）、「团队聊天」（聊天抽屉+对讲开关）。
- 图层新增两个开关（进 §2.2 图层浮层，多人模式时显示）：显示队友位置（默认开）、显示任务范围（默认开）。
- 队长：地图上**划矩形区域→均分为 N 块（默认 4）→分配给队员**（拖拽/点选队员）；重划与下发；查看所有人轨迹/打点/拍照；**转让身份**（成员长按菜单）。本期矩形分块：地图上双指拖出矩形→底部弹出"分为 N 块"滑条→确认后每块圆形范围（块内切圆）下发 zone。
- 队员：收到 zone 高亮+导航可去；对地图上的标记点「到达后点击取消」。
- 观战：只读地图 + 点标记查看图片；无工具箱编辑能力（工具箱隐藏，仅剩图层与 AI）。

## 4. 培训模式（原文 功能3，本期最小可用）
- 大厅胶囊下宽卡片左侧小入口或设置内：**培训模式** = 进入后加载内置演示任务（预置一组示例样本回放），地图按回放速率播放采样动画，配每步白话解说卡（"这是在往基站方向走，信号变强了…"）。回放数据放 assets/training/demo_session.jsonl（lead 提供，若无则由最近真实会话代替）。

## 5. 百度地图接入（lead 负责 SDK/AK，UI 侧只留接口）
- MapEngine 接口已抽象。百度实现由 lead 另行接入（BaiduMapEngine），UI 不需要改动地图调用点，只需保证：图层浮层的"普通/卫星"两个选项能切换 MapEngine 的图层类型，轨迹/采样点/拟合层在引擎上叠加由 lead 处理。
- Canvas 兜底继续保留（无 SDK 时自动降级）。
