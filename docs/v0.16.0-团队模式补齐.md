# v0.16.0：团队模式补齐（第一批）

## 背景
团队模式此前缺少单人模式的多项能力：没有目标小区 → 命中判定恒 false；
没有覆盖拟合/统计；退出即删团队会话 → 无法回看复盘。

## 本次已完成

### 1. 团队任务目标（可选）
- 入口：多人协同页「服务器」下方新增「团队目标（可选）」，支持 ECI / NCI / 经纬度 R=1800 等格式；
- 留空 = 不判定命中（只记录轨迹）；
- 实现：`Route.PREF_TEAM_TARGET` → `AppGraph.teamTask()` → `AppGraph.ensure(..., teamTask())`。

### 2. 团队地图的本人覆盖拟合
- 团队地图现在调用 `CoverageFitter.fit(本人样本)`，绘制 hull（含洞，青色）；
- 左下角新增统计条：`本人 N 采 · 面积 · 置信 xx%`；
- 与单人模式同源（同一 `CoverageFitter`），但**只统计本人样本**，不是全队汇总。

### 3. 团队会话保留 + 历史可见
- 退出房间不再删除 `team-<roomId>` 会话（v0.14.4 的删除逻辑已移除）；
- 历史页 `listSessions(includeTeam = true)` 展示团队会话，并加「团队」角标；
- 首页「最近任务」仍只显示单人任务（避免团队会话抢占）。

## 风险与注意
- 团队会话不再自动清理：`sessions/team-*` 会累积，需在历史页手动删除或后续加 TTL；
- 覆盖统计是「本人」口径，不能当作全队覆盖对外汇报；
- 团队目标留空时 `onTarget` 仍恒 false，成员命中高亮不会亮，这是预期行为。
