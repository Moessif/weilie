# v0.13.3 变更说明：内洞支持 + 面积口径统一

> 基线：v0.13.2（双引擎自动选优）
> 本次解决两个"可信度"问题：**中间没走过的区域被涂成覆盖区**、**界面/导出/报告的面积不是一个数**。

---

## 一、问题

| 现象 | 根因 |
|---|---|
| 绕着院子走一圈，地图把**院子中间也涂成绿色**，面积虚大 | 成面只保留外环（`TrackBufferArea` 取最大环，`AlphaShape` 输出单环），没有"洞"的概念 |
| 报告写"覆盖 XX 平方米"，导进 QGIS/Google Earth 一算对不上 | 面积算法与导出几何不同源：界面用鞋带公式，导出写另一条环 |

---

## 二、改动

### 1. 新增内洞检测 `CoverageHoles`（纯 Kotlin）

```
1) 环路判定：首尾距离 < 30% 轨迹长度，且轨迹长 > 200 m（否则直接返回空，零开销）
2) 凹包包围盒上铺 2 m 网格，把"每个格子到最近轨迹线段"的距离盖章进距离场
3) 距离 > 洞半径（默认 平均精度×2，夹 20~60 m）的连续内部区域 = 候选洞
4) Marching Squares 取等值线成环
5) 过滤：面积 < 300 m² 丢弃；贴外边界（< 1.5 格）的丢弃——那是"海湾"不是洞
```

输出：`holesLocal` / `holesLatLon` / `areaM2`。

### 2. 面积口径统一（`CoverageResult` 新增字段）

| 字段 | 含义 |
|---|---|
| `hullAreaM2` | 外环面积 |
| `holesAreaM2` | 洞面积合计 |
| `coverageAreaM2` | **覆盖面积 = 外环 − 洞**（界面、导出、报告统一用这个） |
| `bufferedAreaM2` | 缓冲带面积（仅展示不确定带，不计入覆盖面积） |

导出与界面都从同一组环计算，**GIS 算出来的数 = App 显示的 数**。

### 3. 渲染

- **百度地图**：`PolygonOptions.addHoleOption(PolygonHoleOptions...)`，凹包与缓冲带都挖洞；
- **Canvas 兜底**：`Path.fillType = EvenOdd`，外环 + 洞一起填充；
- 历史详情统计区新增一行：`覆盖面积 16275 m²（外环 27185 − 洞 10910）`。

### 4. 导出

- **KML**：`<innerBoundaryIs>` 逐洞输出，`<description>` 写覆盖面积 / 外环面积 / 洞数 / 引擎；
- **GeoJSON**：`Polygon.coordinates = [外环, 洞1, …]`，`properties` 增加 `area_m2`、`hull_area_m2`、`holes`、`engine`。

### 5. 顺手修掉一个老 bug

`GeoJSON` 多个 feature 之间**缺少逗号**，导出的文件其实不是合法 JSON（QGIS 会报错）。
已在 `appendFeature` 里补分隔符——这是 v0.13.0 起就存在的问题。

## 三、验证

```
$ gradle testDebugUnitTest
BUILD SUCCESSFUL
30 个测试类 / 210 个用例 / 0 失败     ← v0.13.2 的 202 + 本次 8
```

新增用例：

| 测试类 | 覆盖点 |
|---|---|
| `CoverageHolesTest`（5） | 环路 → 1 个洞、直线 → 无洞、小环忽略、环路判定、拟合面积 = 外环 − 洞 |
| `ExporterHoleTest`（3） | KML 含 `innerBoundaryIs`、GeoJSON 双环 + 面积属性、无洞时单环 |

真机（vivo V2458A / Android 16，v0.13.3）：

- 注入半径 80 m、18 点的环形走测；
- 地图显示为**空心环**（中间透出底图）；
- 历史详情显示：

```
拟合引擎   轨迹缓冲 · 有效点仅 18 个（< 30），改用轨迹缓冲（半径 15 米）
覆盖面积   16275 m²（外环 27185 − 洞 10910）
```

数值与几何一致：外环半径 ≈ 95 m（80+15）→ 面积 2.8 万 m²，洞半径 ≈ 60 m（80−20）→ 1.1 万 m²。
