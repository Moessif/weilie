## 一、本轮两个问题

用户反馈（真机）：

1. 「实测封闭区域这个逻辑做得还是不好，要不就加一个模拟实测区域的选项，把轨迹附近的一定区域渲染成实测区域：以轨迹上的点为中心画圆或者方块，沿轨迹能移动到的地方为模拟实测区域，圆/方块大小可设定」
2. 「新建任务刚进地图的时候，地图上会有一个非常大的点覆盖，然后过一会儿会变小成正常的，暂停走测再恢复也会消失」

## 二、模拟实测区域（新能力）

### 2.1 两种成面方式

图层面板 → 叠加图层 → 实测封闭区域 → 「成面方式」：

| 方式 | 说明 | 适用 |
| --- | --- | --- |
| 高精度凹包（默认） | 用有效实心点做 Alpha Shape 凹包；点太少/共线时退化为沿线带 | 走测点足够、想贴合真实覆盖形状 |
| 模拟实测区域 | 以每个轨迹点为圆心（或方块中心）画半径 R 的圆/方块，沿轨迹自动融合成一整片 | 点少、轨迹零散、只想表达「走到哪、测到哪」 |

模拟区域可调：

- **圆/方块大小**：±5 m ～ ±200 m（默认 ±30 m，写入 `map_area_buffer_radius`）
- **形状**：圆形 / 方形（写入 `map_area_buffer_shape`）
- 开关与选项都会记住，下次进入保持

### 2.2 实现

- 新增 `core\fitting\TrackBufferArea.kt`：把采样点投影到局部平面 → 按 `radius` 生成距离场（圆=欧氏距离，方=切比雪夫距离）→ MarchingSquares 取 0 等值线最大环 → Douglas–Peucker 简化 → 转回经纬度。
  - 网格步长 `max(radius/8, 跨度/200)`（clamp 0.75..6 m）→ 30 m 圆能得到 14 个以上顶点，不再是大棱角多边形。
  - 每个点只写 `radius*1.2/step+2` 邻域，1000 个采样点也只算十几万次距离，不卡 UI。
- `core\fitting\AreaBuilder.kt` 增加 `Mode{AUTO, SIMULATED}` 与 `Kind.SIMULATED`；`build()` 统一先过 `TrackSanity`。
- 新增 `core\fitting\TrackSanity.kt`：剔除飞点（经纬度非有限 / 越界 / (0,0) / 精度 >120 m / 距中位位置 >3 km），单点不影响整体。
- UI：`ui\map\MapLayersPanel.kt` 增加「成面方式」「圆/方块大小」「形状」；`SingleMapScreen`、`TeamRoomScreen` 均已接线并持久化（多人页与单人页行为一致）。
- 面板过高问题顺带修复：图层面板改为可滚动，最大高度 = 屏高 − 140 dp，小屏也能点到最下面的选项。

### 2.3 真机验证

- 图层面板：三项叠加图层开关均可点；「成面方式」两枚 pill 可切换；滑杆与形状 pill 正常。
- 渲染：恢复含 6 个采样点的任务后，地图上出现以当前位置为中心的青色多边形实测区域（约 ±30 m），随轨迹延展；多人页同样渲染。

## 三、进图「巨大圆点」根因与修复

### 3.1 根因

覆盖物半径按「米」绘制，米/像素由 **zoom** 换算：`156543.03392 * cos(lat) / 2^zoom`。地图刚创建时 `map.mapStatus.zoom` 为 0（或尚未稳定），换算出的米/像素极大，圆点半径被放大上千倍；等到地图状态回调落定后才变小——与用户描述的「先巨大、过一会儿正常」完全吻合。暂停/恢复会触发一次重绘，也会恢复正常。

### 3.2 修复

- 渲染器不再读 `map.mapStatus.zoom`，改为由 Compose 侧把 **相机 zoom**（`camera.zoom + BAIDU_ZOOM_OFFSET`）作为 `zoomBaidu` 参数传入；`BaiduOverlayRenderer` 内部保存 `scaleZoom` 并 clamp 到 4..22，`metersPerPixelAt()` 只用 `scaleZoom`。
- 内容指纹带上 `scaleZoom`，缩放时覆盖物会按新比例重建，不会残留旧尺寸。
- `core\fitting\CoverageFitter.kt` 也统一走 `TrackSanity`，避免单个飞点把理论覆盖凸包撑到城市尺度（用户上一轮说的「异常覆盖」的另一条来源）。
- 真机连拍：进图 0.9 秒时蓝点即为正常尺寸，无巨大圆。

## 五、使用建议

- 走测点比较少（<8）、或走得比较散时，用「模拟实测区域」，把圆/方块设成 ±20~50 m，能得到连续、好看的区域；
- 点数足够多、想要贴合真实覆盖边界时，用「高精度凹包」；
- 无论哪种模式，都可以随时在图层面板切换，不影响已保存的采样数据。
