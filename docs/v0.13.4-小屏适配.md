# v0.13.4 变更说明：小屏适配（手机竖屏）

> 目标：只覆盖手机竖屏（320–480dp 宽），不追平板/折叠屏/横屏。
> 验证方式：`adb shell wm size/density` 模拟 320×568dp，系统字体 1.25 倍。

---

## 一、复现

| 档位 | 结果 |
|---|---|
| 360×800dp（原生） | 正常 |
| **320×568dp** | **底部导航整个消失，页面不可滚动 → 进不了历史/设置** |
| 320×568dp + 字体 1.25 | 数据栏「服务小区信号」换行、右侧浮动按钮压住「详情」 |
| 320×568dp + 工具箱 | 5 列网格把「切换基站/数据导出」截成「切基站/数据导」 |

---

## 二、改动

### 1. 首页：底部导航常驻（关键）

- 内容区改为 `Column(weight(1f).verticalScroll(...))`，停靠栏在滚动区之外；
- 去掉滚动容器内无效的 `Spacer(weight(1f))`；
- 雷达从固定 300dp 改为 `0.82 × 屏宽`、上限 300dp。

### 2. 数据栏（`MapDataBar`）

- 标签列 76dp → 72dp，强制单行 + 省略号；
- 「服务小区信号」→「主区信号」，「样本计数」→「样本数」（更短、口径一致）；
- 小屏（<360dp）右侧留 44dp 安全区，避免被 AI 浮动按钮压住。

### 3. 工具箱（`MapToolbox`）

- 网格列数：`chunked(5)` → 小屏 `chunked(4)`；
- 工具格标签支持 **2 行**、字号 11→10sp、格高 `heightIn(min = 64.dp)`。

### 4. 其余面板（同一批）

| 位置 | 改动 |
|---|---|
| `MapLayersPanel` | 宽 268dp → `widthIn(max=268)` + `fillMaxWidth(0.82f)`；最大高度夹在 220–620dp |
| `AiSheet` | 消息区固定 340dp → `heightIn(180dp, 屏高×0.45)` |
| `TeamRoomScreen` | 图层面板高度 `屏高−顶部−200` → 夹在 200–640dp |
| `HomeScreen` 通知卡 | `.width(300.dp)` → `widthIn(max=300)` + `fillMaxWidth(0.88f)` |
| `AndroidManifest` | `screenOrientation="portrait"`（按决定不处理横屏） |

## 三、验证结果

| 项 | 结果 |
|---|---|
| 单测 | **210 / 210 通过** |
| 320×568dp 首页 | 停靠栏可见、可滚动 ✅（截图 `ui-shots/p320-home-fixed.png`） |
| 320×568dp 数据栏 | 标签单行、详情不被遮挡 ✅（`p320-map-fixed2.png`） |
| 320×568dp 工具箱 | 4 列，长标签可换行（`p320-toolbox-fixed2.png`） |
| 原生 360×800dp | 无回归 ✅（`native-home-after.png`） |
| 显示参数 | 已 `wm size/density reset`、字体恢复 1.25 |

### 逐屏验证结果（第二轮）

| 界面 | 360×800dp（原生） | 320×568dp | 结论 |
|---|---|---|---|
| 图层面板 | ✅ 正常展开（普通/卫星/轨迹） | ❌ 点击「图层」无反应，面板不出现 | **小屏专属点击失效，待查** |
| 数据栏展开箭头 | ✅ | ❌ 点击无反应 | 同上 |
| 工具箱 | ✅ | ✅ 可开、可滚动 | 正常 |
| AI 面板 / 多人页 / 通知卡 | 未测（受上面问题影响，先修点击） | 未测 | 待测 |

补充：已在 `SingleMapScreen` 给图层面板高度加了 `coerceIn(220.dp, 560.dp)`
（原公式在小屏会算出 18dp，面板等于隐形），但**即使高度修好，320dp 下按钮本身收不到点击**，
说明还有一层覆盖物/命中测试问题，需要在下一轮单独排查。
