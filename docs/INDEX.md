## 六、跨文档统一约定

1. **占位标记**：`【待填】`＝需人工补充；`【待试验后填写】`＝须实测数据填充。全文检索这两个标记即可得到当前欠账清单。
2. **数据口径**：试验完成前，一切指标以"目标值"表述；实测值只出现在标注【待试验后填写】的位置，且必须与 CSV 原始数据对账。严禁以估算值冒充实测值。
3. **文件命名**：申报材料 `围猎-材料名-版本.ext`；试验数据遵循采集计划第八节命名规则。
4. **图表同源**：报告架构/数据流/算法链图与申报材料"原理结构图"同一源文件绘制，避免两套口径。
5. **版本记录**：每份文档末尾保留版本记录表，修订必记。
6. **口径冲突处理**：并行产出的文档若与本文档口径冲突（如时间线、阈值），以 INDEX.md 第三节速查表为唯一权威源，发现冲突即回改。

## 八、新成员上手 FAQ

**Q1：我刚加入团队，从哪里开始？**
A：读本页第三节建立全貌 → 找负责人认领分工 → 按第二节速览表定位你要用的文档 → 从该文档的版本记录与【待填】标记入手。

**Q2：我要改某份文档，流程是什么？**
A：直接修改 → 文末版本记录表追加一行 → 回本页第一节更新该文档"状态/下一步"列。涉及关键信息（时间线、邮箱、指标口径）的修改，必须先改本页第三节。

**Q3：试验数据什么时候能填进报告？**
A：按第四节时间线，2026-12 月底数据归档并验收"通过"后；此前报告相关位置一律保留【待试验后填写】。

**Q4：实名版材料什么时候开始做？**
A：材料组装期（2027-01 上旬）；但《申报书素材.md》已备好成稿文字，拿到官方模板后即可快速组装，无需从零写。

**Q5：服务器什么时候就绪？**

## 九、术语速查（详见报告附录 A）

| 术语 | 含义 |
| --- | --- |
| ECI / NCI | LTE / NR 的小区全局标识（含基站 ID + 小区 ID） |
| LAC + CI | 2G/3G 的位置区码 + 小区标识 |
| RSRP / RSRQ / SINR | 参考信号接收功率 / 质量 / 信号干扰噪声比 |
| PCI / EARFCN | 物理小区标识 / 绝对射频信道号 |
| IDW（p=2） | 反距离加权插值，权重 1/d² |
| 凸包 / 缓冲带 | 点集最小外包多边形（Andrew 单调链）/ 边界外扩安全余量带 |
| Marching Squares | 栅格等值线提取算法（16 case + 鞍点消歧） |
| JSONL | 每行一个 JSON 对象的追加式存储格式 |
| onTarget / targetSeen | 打点帧命中目标小区的标记字段 |
