## 二、作品摘要（约 300 字）

基层公安单位普遍缺乏路测仪等专用装备，办案中只有上级下发的基站编号与粗略覆盖范围，难以收敛为可行动的精确边界。本作品研制「围猎」系统，在免 root、无专用设备前提下，用普通安卓手机完成目标基站覆盖边界的多人在途协同实测：四种上级参数格式智能解析一键建任务；免 root 采集双卡小区标识与 RSRP 等打点数据；以「凸包+缓冲带+IDW 插值+等值线提取」多源融合拟合覆盖边界与热力图，并输出量化置信度；WebSocket 支撑队长划区、分片围测、实时汇聚；取证相机为照片烧录时间、地址与蜂窝参数水印，影像验真以 SHA-256 与 HMAC 签名支持第三方独立核验；结果可导出 CSV/GeoJSON/KML。全自研、权限最小化、不涉及敏感网络能力，为无装备条件下的覆盖定位提供轻量协同解决方案。

（字数：Word 口径 299 字（英文串按词计），逐字符口径 350，达标 ≤300；已删制式括号列举、「支持 5G NSA 识别」、置信度公式（完整表述见「技术路线」字段）与 Marching Squares 全称；如需进一步压缩，可再删「结果可导出 CSV/GeoJSON/KML」一句）

## 三、立项目的

1. **破解基层装备痛点**。县分局一级普遍无路测仪、扫频仪，而办案中确定目标基站真实覆盖范围又是划定搜捕圈、部署盘查力量的关键环节。本项目旨在证明：不依赖专用装备，仅凭民警随身携带的普通安卓手机即可完成该任务，把「无装备困境」转化为「人人皆传感器」的优势。该路线已工程落地：核心解析与算法层 **50 项单元测试全部通过**，服务端部署于阿里云 ECS 在线可用，工程成熟度达到可演示、可实测状态。
2. **打通参数到边界的技术断层**。上级下发的基站参数格式不一（ECI/NCI/LAC+CI/经纬度），且附带范围粗略（半径可达 1 公里）。本项目建立从「任意格式参数」到「带置信度的精确覆盖边界」的完整技术链路，消除参数壁垒与范围模糊。
3. **探索多人在途协同的实战作业模式**。单人走测耗时且易留盲区，本项目将多名民警组织为分布式「传感器阵列」，分片围测、实时汇聚，用协同提升测量完整性与效率。
4. **树立公安工具类应用的合规范式**。在全自研、权限最小化、功能负面清单的约束下完成全部功能，为同类「技术赋能基层」项目提供可复制的合规开发样本。
5. **服务公安教育与训练**。系统的录制回放与培训模式可沉淀为实战化教学案例，反哺公安院校通信技术教学。

## 四、创新点

**创新点 1：四种上级参数格式的容错智能解析。**
支持 ECI/NCI/LAC+CI/经纬度+半径四类格式及其常见变体（十六进制 0x 前缀与 H 后缀、MCC-MNC 前缀、全半角与中英文标点混杂）。解析前 NFKC 归一化，解析后按位数启发式自动推断制式、自动拆解 eNodeB 与 CID 供核对，失败时输出人话错误——「贴进来就能建任务」，适配高压作业环境。

**创新点 2：免 root 普通手机的多制式信号采集链路。**
仅用公开 API `TelephonyManager.getAllCellInfo()` 即同时获取服务小区与邻区的标识、频点与 RSRP/RSRQ/SINR，毫秒时戳时空打点，JSONL append-only 本机持久化保证测量记录不可篡改；全程不申请 READ_PHONE_STATE，不碰任何 root/隐藏通道。

**创新点 3：多源融合的覆盖边界拟合算法（核心）。**
五级流水线「内点凸包→米制缓冲带（25 m+平均定位精度×0.5）→IDW 插值（12 m 网格）→Marching Squares 等值线提取→置信度评估」，同时给出凸包（人到过哪）、缓冲带（测量不确定带）、等值线（信号到得了哪）三种互补边界；置信度=样本量因子×0.5+16 扇区方向覆盖度×0.5，把「采了多少」与「围得全不全」同时量化为 0–100 分与低/中/高三档。算法全 JVM 可单测。

**创新点 4：多人分片围测的协同架构。**
Ktor+WebSocket 实现队长划区、队员分片扫围、位置/打点摘要/照片实时共享与文字图片聊天；多方位样本天然提升 16 扇区方向覆盖度，协同模式与置信度算法形成正反馈闭环——这是单人单机的传统路测软件不具备的作业形态。

**创新点 5：带白名单域守卫的受控 AI 助手。**
接入 DeepSeek v4.1 flash（适配器可切私有化端点）提供拍照场景分析与技术答疑，以白名单域守卫限定提问边界，key 用户自配、不内置不上传，在获得 AI 增益的同时守住警务数据安全与合规底线。

**创新点 6：影像验真——取证照片可第三方独立复核（2026-11-07 新增，供申报书表一创新性栏选用）。**
拍照落库即算文件 SHA-256 登记自建服务，服务端签发 8 位验证码并以 HMAC-SHA256 对「验证码+哈希+时间戳+坐标」签名，登记表 JSONL 追加写；第三方扫码即可完成三项校验（登记记录存在 / 图片哈希一致 / 签名有效），照片被修改或登记被伪造即失败，离线拍摄先排队、联网自动补登。哈希锁内容、HMAC 锁登记行为、验证码与二维码供复核，为无专用取证装备的基层提供轻量级证据可信方案。

## 五、技术路线

**总体路线**：「端—云」两层架构。Android 端（Kotlin 2.0.21 + Jetpack Compose）五层分层：采集层→数据层→算法层→呈现层→协同接入层；服务端（Kotlin 2.3.x Ktor + WebSocket）已部署阿里云 ECS（2 核 4 G，Ubuntu 24.04，systemd 托管，另提供 docker-compose 一键部署方案）。

**关键技术路线**：

1. **任务建立**：`TaskInputParser` 对上级参数做 NFKC 归一化→四格式正则匹配→制式启发推断→结构化 `TargetCell`，一键建任务。
2. **走测采集**：TelephonyManager `getAllCellInfo` 免 root 轮询服务/邻区（CI/PCI/EARFCN/RSRP/RSRQ/SINR）+ GNSS 定位，毫秒时戳，JSONL append-only 会话存储 + manifest 索引。
3. **覆盖拟合**（纯 JVM，可单测）：
   - 样本过滤（GPS 精度 > 60 m 剔除，总量 < 8 不拟合）→
   - RSRP ≥ 阈值（默认 −110 dBm，6 档可配）筛内点 →
   - 质心米制局部坐标化 → 内点二维凸包 → 外扩缓冲带（25 m + 平均精度×0.5）→
   - 全样本 IDW 插值 12 m 热力网格 → Marching Squares 提取阈值等值线（取最长前 3 条闭环）→
   - 置信度 = min(1, 样本数/120)×0.5 + 16 扇区内点方向覆盖度×0.5，映射低/中/高；
   - 结果双坐标系输出（米制局部 + WGS-84 经纬度）。
4. **多人协同**：队长建房划区 → 队员 WebSocket 加入分片围测 → 位置/打点摘要/照片/聊天实时同步 → 服务端内存态+JSON 快照持久化。
5. **取证与验真**（2026-11-07 新增）：全屏 CameraX 取证相机，拍照即在照片左下角烧录双段水印（大字时间+日期/星期+百度逆地理地址+可编辑备注；逐 SIM 卡的运营商/制式频段/NRARFCN-EARFCN/PCI/NCI-ECI 分解/RSRP/SINR 数据块），相机内可选 5 类取证对象（普通取证/隐蔽摄像头/可疑摄像头/可疑设备/其他），拍照即按 GPS 位置在地图落标点、点击回看照片与当时现场数据；影像验真链路=拍照算 SHA-256→登记 Ktor 服务→服务端 8 位验证码+HMAC-SHA256 签名（原文 `code:sha256:serverTs:ts:lat:lon`）→JSONL 注册表→详情页验证码与 `WEILIE-VERIFY:<code>` 二维码→第三方三重校验（登记/哈希/签名），离线拍摄本地排队、联网补登记；验真服务已上线 `http://47.89.181.85:8080`（`POST /api/photo/register`、`GET/POST /api/photo/verify`、`GET /api/photo/count`）。
6. **双卡与制式识别**：`createForSubscriptionId` 按订阅卡分别取小区，NR 优先、LTE+NR 邻区补 NR 行，ROM 过滤 NR 时以 `dataNetworkType` 兜底标 `NR(NSA)`；NCI 36bit 按 gNB×4096+CID(12bit) 分解、ECI 28bit 按 eNB×256+CID(8bit) 分解，十进制/十六进制/分解式三种展示。
7. **呈现与输出**：Compose 普通模式（信号条+白话时间线）/专家模式（全工程字段）双轨 UI；主题系统支持明/暗/跟随系统 + 10 个预设主题色 + 自定义色相/饱和度，选中即生效并持久化（适配夜间执勤与强光环境）；MapEngine 抽象地图层，Canvas 迷你地图兜底；会话导出 CSV（字段自定义）/GeoJSON/KML 进 GIS 流程。
8. **AI 助手**：DeepSeek v4.1 flash 云 API，白名单域守卫，拍照场景分析+技术答疑。
9. **质量基线**：单元测试 50 个全绿（CellCodec 9 / TaskInputParser 13+6 / SimCellPlanner 12 / 拟合 10）；客户端单 APK 双架构（arm64-v8a + x86_64），minSdk 26 / targetSdk 35；服务端健康检查 `/api/health`，WebSocket 多人联机房间服务在线。
10. **验证路线**：与 CellularPro 原版同机同小区对拍定标（**计划口径，实测数据待采集回填**）→ 六场景（城市密集/城郊开阔/山区遮挡/室内弱覆盖/边界收敛/协同演练）真机实测 → 协同链路性能压测。

## 六、预期成果

## 七、应用价值

1. **实战价值**：让无装备的基层所队在接警后即可组织 4–8 人的围测小组，把上级给的 1 公里级粗略范围在短时间内核实收敛为带置信度的精确边界，直接支撑搜捕圈收缩、盘查卡点布设与指挥决策；导出的 GeoJSON/KML 可直接进入指挥调度 GIS。
2. **推广价值**：零专用硬件投入、零授权门槛（免 root、最小权限）、docker 一键部署，适配公安内网环境私有化部署；作业方法可复制到大型活动安保、要害部位信号核查、应急通信保障等场景。
3. **教育训练价值**：录制回放与培训模式可构造室内化教学场景，支撑公安院校《移动通信》《公安信息化》等课程的实训教学，学员无需专用装备即可理解蜂窝覆盖与路测基本原理。
4. **合规示范价值**：全自研、权限最小化、功能负面清单的开发范式，为公安科技类学生创新作品在知识产权与网络合规方面提供参照样板。

## 九、附：可直接引用的量化表述（供申报书正文嵌入）

- 上级粗略范围最大按半径 1000 m 计，参考面积约 **314 万平方米**；本作品通过实地围测将搜索范围收敛至以实际覆盖边界计的面积（城市密集场景收敛率待实测回填，见研究报告表 5-3）。
- 边界拟合最少 **8 个**有效样本即可启动；**120 个**有效样本置信度样本量因子饱和；16 扇区方向覆盖度达 **12/16** 且综合得分 ≥ 70 即评定「高置信度」。
- 缓冲带宽度自适应：**25 m 基础值 + 平均定位精度×0.5**，定位质量差时边界自动保守外扩。
- 等值线阈值 **6 档可配**（默认 −110 dBm），适配不同现场判定口径。
- 工程质量：**50 项单元测试全部通过**（CellCodec 9 / TaskInputParser 19 / SimCellPlanner 12 / 拟合 10）；服务端已部署阿里云 ECS（2 核 4 G，Ubuntu 24.04，systemd），健康检查 `/api/health`。
- 影像验真：8 位验证码；签名原文 `code:sha256:serverTs:ts:lat:lon`（HMAC-SHA256）；照片被修改或登记被伪造均导致校验失败。
