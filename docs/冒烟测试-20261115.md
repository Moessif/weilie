# 本地冒烟测试记录（2026-11-15）

环境：Windows + JDK 17，`java -jar artifact/weilie-server-all.jar`，
数据目录 `%TEMP%\weilie-smoke-data`，端口 8080，`WEILIE_ROOM_TTL_DAYS=7`。

| 检查项 | 命令 | 结果 |
|---|---|---|
| 健康检查 | `GET /api/health` | `{"ok":true}` ✅ |
| 指标 | `GET /metrics` | 返回 `weilie_rooms`、`weilie_online_members` 等 ✅ |
| 建房 | `POST /api/teams {"name":"smoke"}` | `{"roomId":"03c29c4c35be","joinCode":"890845"}` ✅ |
| 房间概览 | `GET /api/rooms` | 含 roomId/name/createdAt/lastActiveAt ✅ |
| 导出鉴权 | `GET .../export?code=000000` | **403** ✅ |
| GeoJSON 导出 | `GET .../export?code=<正确码>&format=geojson` | 合法 FeatureCollection ✅ |
| CSV 导出 | `...&format=csv` | 表头 `userId,ts,lat,lon,rsrp,onTarget` ✅ |
| 关闭房间 | `POST .../close?code=<正确码>` | `{"ok":true}` ✅ |
| 审计日志 | `data/audit.jsonl` | 4 行（room_create / export / room_close 等）✅ |

结论：打包的 jar 可独立启动，运维接口与鉴权行为符合预期；
