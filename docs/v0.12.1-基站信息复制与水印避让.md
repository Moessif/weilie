# v0.12.1 基站信息一键复制 + 相机水印避让

两个都是真机反馈的小问题，改在客户端，服务端无改动。

## 一、SIM 卡行加“复制基站信息”按钮

**位置**：地图页数据栏，每张 SIM 卡那一行的右侧、信号格左边，一个 28dp 的隐式图标按钮（`Icons.Rounded.ContentCopy`）。

**复制内容**（一行，便于转发给内勤/外勤）：

```
中国移动 NR N41 · 46000 · 1385911-1 · PCI 734 · ARFCN 504990 · RSRP -87 dBm
```

- 有 MCC/MNC 才带，PCI/ARFCN 为未知（`Int.MIN_VALUE`）时不输出，RSRP 未知时不输出；
- 复制后弹 toast「已复制基站信息」；Android 13+ 系统还会弹出剪贴板预览，可直接确认内容；
- 实现：`ui/map/MapDataBar.kt` 的 `SimRow` 里加按钮，复制文本由 `cellCopyText(SimCell)` 生成。

**为什么复制整行而不是只复制编号**：现场沟通时对方需要同时知道是哪个运营商、哪个频段、哪个小区，只给一串数字反而要来回问；这一行既覆盖工参又保留 ID。

## 二、相机页取证类型按钮压在水印上

**现象**：`weilie/dist` 里真机截图能看到“普通取证 / 隐蔽摄像头 / 可疑摄像头 / 可疑设备 / 其他”五个按钮压在水印文字上。

**根因**：水印块用固定的底部内边距 `Space.x8 * 5 + Space.x4 = 176dp` 定位，而底部控制区（取证类型 chips 两行 + 快门 + 相册）实际高度约 220dp。v0.12.0 把 chips 从一行可横滑改成 `FlowRow` 两行后，控制区变高，但水印的固定偏移没跟着变，于是叠在一起。

**修复**：`ui/camera/PhotoCameraScreen.kt`

- 底部控制区 `Column` 加 `onGloballyPositioned { controlsPx = it.size.height }`，运行时量出真实高度；
- 水印块底部内边距改为 `with(density) { controlsPx.toDp() } + Space.x6`，即始终停在整个控制区上方再留 24dp；
- 只影响屏幕预览的排版，烧进照片的水印位置不变（照片里没有这些按钮）。

## 四、复核建议

1. 真机进地图页，点 SIM 行右侧复制图标，粘贴到微信/短信确认一行内容完整；
2. 打开相机，确认五个取证类型按钮在水印下方，不再压字；
3. 横竖屏与不同字号下再看一眼：水印与控制区靠运行时测量，不依赖固定 dp，理论上跟随布局稳定。
