## 四、风险提示

1. **软删除**会让 `snapshot.json` 与内存中的 `zones` 逐渐变多（含已删项），长期需配合 TTL/定期归档；
2. **采样落盘**按房间累积，12 人 × 8 小时约几十 MB/房间，需依赖 TTL 清理；
3. **审计日志**含 userId 与操作，属敏感数据，备份与访问权限需按取证要求管理；
4. 限流阈值按单机试点设定，正式大规模使用前建议压测后调整。
