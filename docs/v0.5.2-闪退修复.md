# v0.5.2 闪退修复（Compose Constraints 溢出）

## 现象

真机（高密度屏，密度 ≥ 3.0）安装后闪退：

```
FATAL EXCEPTION: main
Process: com.gakj.weilie
java.lang.IllegalArgumentException: Can't represent a width of 304989 and height of 0 in Constraints
    at androidx.compose.ui.unit.ConstraintsKt.invalidConstraint(Constraints.kt:459)
    at androidx.compose.ui.unit.ConstraintsKt.createConstraints(Constraints.kt:486)
    at androidx.compose.ui.unit.ConstraintsKt.Constraints(Constraints.kt:558)
    at androidx.compose.foundation.layout.SizeNode.getTargetConstraints-OenEA2s(Size.kt:794)
    at androidx.compose.foundation.layout.SizeNode.measure-3p2s80s(Size.kt:806)
    ...
```

## 根因

Compose（1.7.4）的 `Constraints` 把尺寸打包进 64 位，**每轴上限 262143 px（2^18-1）**，`Modifier.width/height/size` 求出超过上限的固定尺寸就直接抛异常。

本项目里唯一会把「算出来的像素」当固定尺寸用的地方是地图右下角的比例尺 `ScaleBar`：

```kotlin
val mpp = camera.metersPerPixel                      // 156543.03392 * cos(lat) / 2^zoom
val candidates = listOf(25, 50, 100, 200, 500, 1000, 2000, 5000)
val best = candidates.firstOrNull { it / mpp in 60.0..150.0 } ?: candidates.last()
val widthDp = (best / mpp).dp                        // ← 没有上限
```

- 最大缩放（zoom 21，北纬 39.9°）时 `mpp ≈ 0.0574 m/px`；
- 候选刻度全部落空（1m 档不在列表里）→ `best = 5000`；
- `widthDp ≈ 87,000 dp`，密度 3.5 的设备 → **304,989 px**，与报错数字完全吻合；
- `Modifier.width()` 只固定宽、不固定高 → `height = 0`（minHeight）。

**触发路径**：进入一个已有采样的任务 → `LaunchedEffect(samples.size)` 里 `camera.fit(samples)`；
`fit()` 从 zoom 21 起递归，只有 1~2 个几乎重合的点时 `spanM` 很小，循环一次都不进 →
`zoom` 直接停在上限 21 → 比例尺算出 8 万多 dp → 高密度屏上闪退。
（模拟器密度 2.625，同样的值只有 228,742 px，刚好没到 262,143，所以之前一直没复现。）

## 修复

1. `MapCanvas.fit(points, maxFitZoom = 18f)`：自动取景的缩放上限降到 18 级，
   不再「一有采样就拉到最大缩放」，取景更合理，也避开溢出区间。
2. `ScaleBar`：
   - 刻度候选从 **1 m** 起（`1,2,5,10,20,25,50,100,200,500,1000,2000,5000`），任何缩放下都有解；
   - 取「离 100 px 最近」的一档（不再依赖 60~150 的窗口）；
   - `mpp` 非有限/接近 0 时退化为 1.0；
   - 宽度最终 `coerceIn(16.dp, 150.dp)`，从根上保证 ≤ 150dp（≈525px，远低于 262143）。

## 验证

- 模拟器 emulator-5556（1080×2400，密度 2.625）：进入 2 样本任务 → 比例尺显示 `50 m`（zoom 18）✓ 无闪退；
- 连续双击放大到最大（zoom 21）→ 比例尺显示 `5 m` / `10 m`，宽度正常 ✓ 无闪退；
- `:app:testDebugUnitTest` 12 类 98 用例全绿；`:app:assembleDebug` 通过。
