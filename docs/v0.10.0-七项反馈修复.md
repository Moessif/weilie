## 二、关键实现

### 1) 拍照标记删除

- `ui/camera/PhotoDetailSheet.kt`
  - 新签名：`PhotoDetailSheet(photoId, remoteCode = "", onDelete: (() -> Unit)? = null, onClose)`
  - `DeleteMarkerButton(hint, onConfirm)`：危险色描边按钮 + `AlertDialog` 二次确认（标题「移除这个标点？」）。
  - 单人 hint：照片文件保留在本机，仅从地图移除；远程 hint：队友手机上的照片保留，仅从地图与房间移除。
- 单人 `ui/map/SingleMapScreen.kt`
  - `hiddenPhotoMarkers` 读 `PREF_HIDDEN_PHOTO_MARKERS`（`\u0001` 分隔），进入任务回填取证标点时过滤，删除后写回，重启不再出现。
- 多人 `ui/team/TeamRoomScreen.kt`
  - 权限与服务端一致：`it.by == userId || myRole == "CAPTAIN"`；删除调 `room.deleteMarker(mk.id, userId)`。
- 服务端 `weilie/server/.../RoomWs.kt`
  - `Marker` 落库时补 id（`"m-" + nanoTime36`），`PhotoRef` 落标点 id = `"ph-" + photoId` —— 否则「按 id 删除」对拍照标点永远不生效。

### 2) 命中热区

- 图标本体走 SDK `setOnMarkerClickListener`（`clickable(true)` + IdentityHashMap 反查），不受影响。
- `ui/map/MapCanvas.kt`：Canvas 地图 `hitR 24dp → 16dp`。

### 3) 多人页叠加图层

- 状态：`heatOn/heatParams/heatLayer`、`areaOn`（默认读 `PREF_AREA_ON`）/`areaResult`、`libraryOn/librarySites/selectedCell/libraryClient`。
- 计算：热力图 `HeatOverlayBuilder.build`（Dispatchers.Default），封闭区域 `AreaBuilder.build`，基站库 `CellLibraryClient.nearCached(...)`（800 ms 防抖，失败 toast）。
- 渲染：`MapCanvas(heat=, area=, cellLibrary=, selectedCellKey=, onCellSiteClick=)`；`MapLayersPanel` 补 `heatVisible/heatParams/onHeatToggle/onHeatParams/areaVisible/onAreaToggle/libraryVisible/libraryCount/onLibraryToggle/onLibrarySearch`。

### 4) 浅色主题

- 全量排查结论：相机页/扫码页/二维码白底属于深色全屏页与二维码规范，保持不变；地图覆盖物文字走 `MapLabelBg` 深底浅字，浅色主题下同样可读。

- Canvas 兜底地图：同一套 `visualKind()` 画圆底 + emoji + 名称。

## 三、P2：emoji 使用规范（结论）

- **只用在地图图标与图例**：取证类型、手动标点。理由：地图上需要「一眼分类」，emoji 自带颜色、无需美术资源，且与文字标签共存。
- **正文、按钮、表单、对话框一律不用 emoji**：公安场景要求正式、可截图建档；emoji 在部分设备/字体下渲染不一致，也会让水印文字显得不专业。
- 已有 emoji（标点名称由用户输入）不做过滤，由用户自行决定。
