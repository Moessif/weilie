# 管理站视觉重做说明（v1.11.0 · 2026-11-17）

本次重做的对象是 `weilie-platform/web`（Vue 3 + Element Plus + ECharts 管理站），
目标是提升整体视觉质感与信息可读性，**不改动任何接口契约、路由、业务逻辑与权限行为**，
服务端只做了一处展示层的安全收紧（见「服务端唯一改动」）。

---

## 一、约束与做法

- 只做「呈现层」改造：模板结构可重排、样式体系重写、组件可替换，但**数据来源、请求参数、
  表单校验、权限判断、定时器、导出与下载逻辑一律照旧**。
- 页面脚本（`<script setup>`）尽量不动：仪表盘只替换了颜色常量，房间/设置两页脚本逐字节未改。
- 无新增依赖、无新增后端接口；不编造数据（缺少接口的指标一律留空或不展示）。

## 三、设计系统

### 分类与取色

- 品类：**software**（公安无线网络外场采样系统的后台控制台）。
- 取色走「客户自有品牌色」通道：移动端 App 已是「深墨底 + 信号青」，管理站沿用同一血统，
  未采用技能生成的浅色粉调方案（会与 App 品牌冲突）。
- 全部颜色集中在 `web/src/styles/theme.css` 的 `--wl-*` 变量，页面不写字面色值。

### 色板

| 角色 | 值 | 用途 |
| --- | --- | --- |
| ground | `#0a0c11` | 页面底 |
| bg-soft | `#0c0f15` | 侧栏底 |
| panel | `#12161d` | 面板/卡片 |
| panel-2 | `#151a22` | 面板内的次级块 |
| sunken | `#0d1016` | 输入框、缩略图槽、代码块 |
| elevated | `#1a2029` | 弹层（dialog / drawer / message） |
| accent | `#22d3ee` | 主行动、选中态、关键数字 |
| success | `#3ecf8e` | 正常 / 在线 / 已激活 |
| warning | `#f0b429` | 待审核 / 闲置 / 即将过期 |
| danger | `#f2705f` | 停用 / 危险操作 |
| 发丝线 | 6% / 10% / 16% 白 | 三级分割与描边 |

**去掉了旧版的全部装饰性效果**：径向光晕、发光投影、渐变标题、彩色大色块背景。
卡片一律「纯色面板 + 1px 发丝描边」，状态只靠小圆点与文字色表达。

### 字体

- 自托管（不依赖外部 CDN）：`web/public/fonts/` 下 6 个 woff2 子集
  —— `Instrument Sans`（400/700，拉丁正文与标题）、`DM Mono`（400/500，编号、时间、哈希、房间 ID）。
- 中日韩字符回落系统字体（PingFang SC / 微软雅黑 / Noto Sans CJK），避免引入 3 MB 级中文字体。
- 字号阶：页面标题 21px / 面板标题 13.5px / 正文 13px / 表格 12.5px / 标签 11px 大写 0.07em / 等宽数据 12px。
- 数字统一 `font-variant-numeric: tabular-nums`，保证列对齐。

### 间距、圆角、动效

- 内容区 `max-width: 1560px`，左右留白 `--wl-gutter: 28px`，页面上下 `26px / 56px`。
- 圆角 7 / 10 / 14 三档（`--wl-radius-sm/md/lg`），标签与开关用全圆角。
- 动效只有三处：页面切换 0.14s 淡入上移 6px、卡片 hover 变描边、数据行等宽数字不做动画；
  `prefers-reduced-motion: reduce` 时全部关闭。

### 图表主题（`web/src/utils/chart.ts`）

- 序列色：`#22D3EE → #5EEAD4 → #7BA7D7 → #F0B429 → #F2705F → #3ECF8E`（与状态色同源）。
- 轴线 `#7E8A9C`、分割线 5% 白、tooltip 深色 `rgba(26,32,41,.97)` 无毛玻璃。
- 折线 1.6px 平滑 0.25；柱宽 14px 圆角 3px；饼图扇区描边 `#12161D` 与背景融合。
- 面积渐变与柱渐变只保留「单色 → 透明」两段，不再叠加多色霓虹。

## 八、已知限制

1. **移动端表格**：≤720px 时侧栏折叠、页面头堆叠、KPI 两列，但宽表格（房间/用户/审计）仍按桌面列宽压缩，
   仅保留省略号。管理站定位为桌面/平板使用，移动端只保证「能看能操作」。
2. **活跃组织 Top 8**：房间尚未绑定组织，服务端返回空列表，页面显示空态（未编造数据）。
3. **采样趋势 / 在线连接**：指标快照每 60 秒落库一次，新部署后需积累一段时间才有曲线；当前显示 0 基线。
4. **系统监控的磁盘**：接口只提供「可用空间」，无总量，故不显示占用百分比。
5. **房间状态两种口径**：仪表盘「房间状态」按任务区内容分档（有任务区/仅有标点/空房/已关闭），
   房间页状态分段按活跃度分档（在线/闲置/已关闭），二者描述不同维度，非数据冲突。
6. **Element Plus 深色**：主题变量整体重映射，个别第三方组件内部固定色（如 `el-progress` 轨道）仍略带原生灰，
   已在 `theme.css` 内尽量覆盖。
