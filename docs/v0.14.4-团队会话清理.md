# v0.14.4：退出房间即删除团队会话目录

## 问题
每进一次团队房间（队长/队员），都会在
`Android/data/com.gakj.weilie/files/sessions/team-<roomId>/` 下留下 manifest + samples。
历史列表已过滤（v0.14.2），但磁盘会持续累积，且样本含位置轨迹。

## 改动
`TeamRoomScreen` 的 `onDispose`（退出房间）里，在停止采集后调用：

```kotlin
AppGraph.store.deleteSession("team-$roomId")
```

- 复用已有的 `SessionStore.deleteSession()`（只允许删除 sessions/ 直接子目录，防路径穿越）；
- 仅非观战者执行（观战本来不产生会话）；整体 `runCatching` 包裹，失败不影响退出；
- 不删除任何正式任务会话（任务 id 不以 `team-` 开头）。

## 验证（真机）
| 时点 | sessions/ 目录 |
|---|---|
| 进入房间后 | `0568BFBD, 36760DF0, 5E795B4E, EDEEFE6D, team-7c602cf3324d` |
| 退出房间后 | `0568BFBD, 36760DF0, 5E795B4E, EDEEFE6D` ✅ |

单测 210 / 210。
