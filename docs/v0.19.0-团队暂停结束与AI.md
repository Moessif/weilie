# v0.19.0：团队暂停 / 结束全场 / AI / 会话 TTL

## 一、新增
| # | 功能 | 说明 |
|---|---|---|
| 1 | **个人暂停/继续** | 团队地图底部新增「暂停」按钮：只停本机采集与前台服务，房间与其他队员不受影响；再点继续恢复 |
| 2 | **队长结束全场** | 任务面板（仅队长）「结束本次团队采集（关闭房间）」→ 二次确认 → 调服务端 `POST /api/teams/{id}/close?code=` → 成功后退出房间 |
| 3 | **团队 AI 分析** | 任务面板「AI 分析（基于本人数据）」→ 复用 `AiSheet`，摘要含房间/身份/在线人数/样本数/任务区数/本人覆盖面积与置信度/最近采样 |
| 4 | **团队会话 TTL** | 历史页加载时清理 14 天前的 `team-*` 会话（`SessionStore.purgeTeamSessions(14)`） |

## 二、修掉一个真 bug
「结束本次团队采集」确认弹窗此前写成 `confirmEnd?.let { ... }`，
而 `confirmEnd` 是非空 `Boolean` → `?.let` **恒执行**，导致该弹窗一进地图就弹。
已改为 `if (confirmEnd) { ... }`，真机验证不再自动弹出。

## 四、风险
- 「结束全场」会**关闭房间并踢出所有人**，确认弹窗已强调；数据只保留在各成员本机；
- 结束后房间无法恢复（服务端 TTL 也会回收）；
- 团队会话 TTL 清理是**不可逆删除**（14 天），如需保留更久需改参数；
- AI 摘要只含本人数据与全队覆盖面积，不含其他队员明细。
