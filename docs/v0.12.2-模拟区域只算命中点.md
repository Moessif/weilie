# v0.12.2 — 「模拟实测区域」只统计命中目标的采样点

> 版本：`versionCode 28` / `versionName 0.12.2`  
> 触发：真机反馈「为什么出了目标基站区域而且是未命中的情况下还在生成模拟基站区域」

## 一、现象

真机截图里：追踪目标 `NCI 5652803587 未命中`，地图上整条轨迹（含大量灰色的「脱离目标」点）都被一圈绿色模拟实测区域覆盖，**脱离目标的那一段也被算成了实测区域**。

## 二、根因

`core/fitting/AreaBuilder.kt` 的 `build()`：

- `AUTO`（高精度凹包）分支：`sane.filter { isValidPoint(...) }` —— 只取命中目标的点。
- `SIMULATED`（模拟实测区域）分支：直接 `TrackBufferArea.build(sane, ...)`，`sane` 只是 `TrackSanity.saneSamples()` 的**飞点过滤**结果（非有限、精度差、离线 3 km 的异常点），**没有按目标命中过滤**。

所以只要手机还在记录采样点，不管有没有连上/看到目标基站，整条轨迹都会铺成「实测区域」。

## 三、修复

### 1. 两种成面方式共用「有效点」集合

```kotlin
val sane = TrackSanity.saneSamples(samples)
val valid = sane.filter { isValidPoint(it, opt.rsrpFloorDbm) }
// SIMULATED：只在 valid 上铺圆/方块；valid < 2 直接返回 NONE
// AUTO：同样只吃 valid
```

`isValidPoint` 的口径（`AreaBuilder.kt`）：

- `onTarget == true`（主区命中，服务小区就是目标），或
- `targetSeen == true`（邻区里出现目标）且 `targetRsrp ?: rsrp >= rsrpFloorDbm`（默认 -110 dBm）。

也就是说：**主区命中必算；邻区命中要信号够强才算；完全脱离目标的点一律不算**。

### 2. 顺带修：缓冲面从「孤立圆」改成「沿轨迹的走廊」

新测试暴露出一个隐性 bug：`TrackBufferArea` 原来是在每个采样点上各画一个圆、取并集的距离场。当两个命中点间距大于直径时，并集会变成**几块互不相连的圆**，而代码只取面积最大的那一块环 —— 地图上看起来就像「只测了其中一段」。

现在距离场改成**到轨迹线段（点与相邻点连线）的距离**：

- `segs = pts.zipWithNext().filter { 两点间距 >= 1m }`，只有一个点时退化成「点-点」；
- 每个网格点取 `radius - distanceToSegment(...)`，圆用欧氏距离、方块用切比雪夫距离；
- 只要轨迹是连续的，走廊就是连续的一整块，不会再漏段。

### 3. 文案

图层面板里「模拟实测区域」的说明改为：

> 只在命中目标的采样点周围铺圆/方块；脱离目标的轨迹不计入实测区域

## 四、测试

- 新增 `app/src/test/java/com/gakj/weilie/core/fitting/AreaBuilderSimulatedTest.kt`（6 例）：
  - 前半段命中、后半段脱离 → 面积只覆盖前半段（宽度 120..190 m）；
  - 邻区命中（-95 dBm）计入；
  - 弱邻区（-125 dBm）排除；
  - 全部脱离 → `Kind.NONE`；
  - 只有 1 个命中点 → `Kind.NONE`（不成面）；
  - AUTO 模式同样忽略 OUT 点。
- 既有 `TrackBufferAreaTest`（8 例）全部通过。
- 全仓：**22 个测试类 / 168 用例 / 0 失败**。

## 五、模拟器可视验证

- 预置 `map_area_on=true`、`map_area_mode=SIMULATED`、`map_area_buffer_radius=30`；
- 任务目标 `5677244420`，模拟器服务小区为 `T-Mobile LTE B1 184-4` → 判定 **未命中**；
- 用 `adb emu geo fix` 注入约 10 个采样点 → 轨迹正常绘制（空心/灰色点），**地图上不再出现绿色模拟区域**（修复前这里会铺满整条轨迹）。
- 截图：`weilie/dist/v0122-check4.png`。

## 六、使用建议

- 想看到「实测区域」：必须真的连上目标小区，或邻区中出现目标且信号高于阈值；
- 只走到目标边缘、邻区很弱时，区域会随之收缩甚至为空，这是符合「实测」语义的；
- 需要「只要走过就算覆盖」的可视化，用 AUTO 模式的兜底带或直接用轨迹图层，不要用模拟实测区域。
