# v0.14.0：成面口径统一（方案 3：B + A）

## 背景
地图上其实叠了两个面：
- 青色 = `CoverageFitter` 的 hull（统计/导出用的就是它，含洞）；
- 绿色 = `AreaBuilder` 的环（内缩、无洞），盖在青色上面。

用户看到的面 ≠ 覆盖面积数字 ≠ 导出几何。

## 改动
### 1. 修 Bug（方案 B）
工具箱「封闭区域」开关原来调用 `AreaBuilder.build(samples)`（默认参数），
忽略了当前的成面方式/半径 → 改为传入 `areaBuildOptions`。

### 2. 统一几何（方案 A）
- **AUTO（高精度凹包）模式**：地图不再画 `AreaBuilder` 的绿色环，
  改为画 `CoverageFitter` 的 hull（含洞、青色），与「覆盖面积」、KML/GeoJSON **同源**；
- **SIMULATED（模拟实测区域）模式**：仍用 `AreaBuilder`/`TrackBufferArea` 生成绿色面，
  图例标注「模拟区域（示意）」，**不参与面积统计**；
- `SingleMapScreen` 不再向地图传独立的 `hullLatLon/bufferedLatLon`，避免重复叠面；
- 图例按模式切换：青色「实测覆盖区」/ 绿色「模拟区域（示意）」。

## 影响
| 项 | 变化 |
|---|---|
| 覆盖面积数字 | **不变**（本来就来自 CoverageFitter） |
| 地图外观 | AUTO 下只保留青色面（含洞、无内缩）；环绕走位中间会挖空 |
| 导出 | 不变（已用 CoverageFitter，含洞与面积） |
| 模拟模式 | 降级为“示意图层”，不参与统计，图例已注明 |
| 理论∩实测 | 交集改用当前 area 的外环（AUTO 下即 fit hull） |
