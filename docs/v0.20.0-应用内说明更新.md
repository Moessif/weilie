- 功能卡片从 4 条扩到 6 条，覆盖当前能力：
  目标解析 / 逐秒采样与命中判定 / 覆盖拟合（洞+面积+置信度）/
  多人协同与任务区 / 导出与复盘（KML·GeoJSON·CSV·PNG）/ AI 现场助手；

- 重写介绍文案：分别说明单人模式与协同模式的完整链路；

- 明确数据边界（本机优先、协同经自建服务器、敏感数据按取证规范管理）与权限清单。

## 三、新增「使用说明」弹层
设置 → 关于 → 「查看使用说明」，含 6 节：
1. 单人走测；2. 协同模式；3. 覆盖口径（本人/全队切换）；4. 角色与权限；
5. 数据与隐私；6. 常见问题（命中不亮、全队覆盖不出现、导出失败、进不去房间）。

## 四、协同页「团队目标」帮助
在「团队目标（可选）」下方加 `HelpHint`，解释：
- 作用：不填则不判定命中；
- 格式：ECI / NCI / 经纬度 R=…；
- 注意：队长统一填写，队员继承，可随时修改。
