# v0.18.0：全队合并覆盖

## 已完成
### 服务端（协议 v1.8，向后兼容）
- `State` 新增 `teamSamples: List<SamplePoint>`（`userId/lat/lon/rsrp/onTarget/ts`）；
- 每次广播 state 时把房间采样**降采样到 ≤1500 点**下发（`mergedSamples`），不落额外存储；
- 老客户端忽略该字段；新客户端连老服务端时该字段为空 → 只显示本人覆盖。

### 客户端
- 团队地图新增「全队覆盖」：用 `teamSamples` 构造样本并调用同一个 `CoverageFitter`；
- 左下统计条改为**可点击切换**：
  - `本人 N 采 · 面积 · 置信%` ⇄ `全队 N 采 · 面积 · 置信%`；
  - 未收到全队样本时提示「点我切全队」不出现；
- 覆盖区域绘制跟随当前口径（本人/全队同一套 hull+洞）。

## 说明与风险
- `teamSamples` 是**降采样**（最多 1500 点），全队覆盖是近似值，面积会比逐点拟合略小；
- 全队覆盖依赖服务端 v1.8+（本轮 jar 已包含）；未升级时只显示本人；
- 每 10 个采样才广播一次 state，全队覆盖刷新有约 10–20 秒延迟；
- 全队样本包含所有成员（含观战者？观战不采集，无样本）。
