# 围猎 v0.5.0 · 新功能说明与真机验收清单

> 对应 `新功能.md` 十章需求。算法实现可按需替换，本文记录当前采用的方案与入口位置。

## 一、本轮新增功能总览

| # | 需求 | 实现方式 | 入口 |
|---|------|----------|------|
| 1 | 路线显示逻辑图层 | 采样点按「主区命中 / 邻区命中 / 脱离」三类绘制：主区=青色实心点，邻区=按服务小区 CI 8 色稳定散列的彩色实心点，脱离=空心圆环；打点间隔默认 1s，可切 1/2/5s | 工具箱 → 「静默跟踪 / 打点间隔」条；地图自动生效 |
| 2 | GPS 双重安检 | `TrackGate`：精度门（>50m 丢弃）+ 距离合并门（<3m 并入上一点，信号值滑动平均）+ 飞点门（>40m/s）+ 卡尔曼平滑；命中门限时地图底部弹出提示 | 自动（采集开启后） |
| 3 | 高精度面积 | 有效点判定「主区命中直接算；邻区命中需 RSRP ≥ -110dBm」；凸包换成 **Alpha Shape 凹包**（Bowyer–Watson 三角剖分 + 边长过滤），点数不足自动退化 | 工具箱 → 数据导出 → 「生成实测覆盖封闭区域」；拟合结果也走凹包 |
| 4 | 队长地图标点/范围 | 标点、拍照改为「先点地图选位置」；任务范围支持**自由绘制多边形**并分配给指定队员（协议沿用 `WsMsg.Zone(kind=POLYGON, assignees)`） | 多人房间 → 标记 / 拍照 / 任务 → 「自由绘制任务范围（点地图落点）」 |
| 5 | 标点与导航 | 点地图上的标点 → 详情弹窗「导航到此」（系统地图意图，失败退高德网页）；单人页同样支持 | 地图标点 / 房间标点 |
| 6 | 信号热力图图层 | IDW 插值 → 栅格位图 → 百度 `GroundOverlay`；强=青绿、中=黄、弱=橙红；网格间隔、扩散半径、透明度可调 | 图层面板 → 叠加图层 → 「信号热力图」 |
| 7 | 带底图导出 + 理论覆盖区 | 用 `BaiduMap.snapshot()` 截真实底图，合成标题栏 + 图例；理论覆盖区支持全向圆 / 扇形（默认 120°）/ TA 环带，与实测相交部分填**紫色** | 数据导出 → 「基站理论覆盖区」「导出轨迹图 PNG（含真实地图底图）」 |
| 8 | 封闭区域生成 | 有效实心点 Alpha Shape 成面；无法成面时按路线生成两侧扩展条带；半透明不遮底图 | 图层面板 → 「实测封闭区域」；数据导出 → 生成/导出 |
| 10 | 静默跟踪模式 | 前台服务（specialUse）持续震动：主区 1s 一次、邻区 0.3s 一次、完全脱离持续震动；无声无弹窗；工具箱开关 + 地图底部常驻状态条 + 通知栏「停止」 | 工具箱 → 静默跟踪开关 |

## 二、算法说明（可选替换点）

- **卡尔曼滤波**：`core/fitting/TrackGates.kt`，2D 匀速模型，`Q=1e-6`、`R=4.0`（`TrackGate(maxAccuracyM, minDistanceM, maxSpeedMs, kalmanQ, kalmanR)`）。
- **凹包**：`core/fitting/AlphaShape.kt`，`adaptiveAlpha = 2.2 × 平均最近邻距离`，三角剖分后按边长过滤边界。
- **面积/条带**：`core/fitting/AreaBuilder.kt`，`Kind.CONCAVE / STRIP / NONE`。
- **热力插值**：`ui/map/HeatOverlay.kt`（IDW，`1/(d²+1)`，半径外不参与），配色 `core/fitting/HeatPalette.kt`。
- **理论覆盖区**：`core/fitting/TheoreticalCoverage.kt`（弧步长 5°），交集 `core/fitting/CoverageIntersect.kt`（Sutherland–Hodgman）。
- **震动节律**：`core/tracking/SilentTrackLogic.kt`（MAIN 80ms/1000ms、NEIGHBOR 40ms/300ms、NONE 持续波形）。

## 三、真机验收清单

1. 打开采集 → 地图上出现青色实心点；走到目标小区覆盖边缘外 → 出现空心点；邻区命中时出现彩色实心点。
2. 打点间隔切成 2s / 5s → 采样点密度随即变化（工具箱内）。
3. 精度差时（室内）底部出现「当前精度 XXm，已跳过」；原地不动出现「距上个点 Xm 小于 3m，已合并」。
4. 图层面板 → 打开「信号热力图」→ 地图出现连续色块；拖动三条滑杆，色块间隔/扩散/透明度变化。
5. 图层面板 → 打开「实测封闭区域」→ 出现半透明绿色面（点少时是沿轨迹的条带）。
6. 数据导出 → 「基站理论覆盖区」→ 填方位角 60、距离 800 → 出现蓝色扇形 + 橙色 TA 带。
7. 数据导出 → 「导出轨迹图 PNG（含真实地图底图）」→ 分享出的图片含真实底图 + 图例。
8. 工具箱 → 静默跟踪开关 → 手机开始按状态震动；锁屏/息屏仍震动；通知栏有「停止」按钮；地图底部有状态条可点停。
9. 多人房间：队长标点 → 队员点该点 → 「导航到此」；队长「自由绘制任务范围」→ 地图落点 → 完成后选择分配给某队员 → 该队员地图出现多边形任务区。
10. 拍照：点「拍照」→ 顶部提示「点击地图选择位置」→ 点地图 → 相机打开 → 拍完标点落在点选位置（不是手机当前位置）。

## 五、v0.5.1 补齐（2026-11-08，按需求原文逐条复核后补的缺口）

复核 `新功能.md` 十章时发现 6 处「有功能但没完全照要求做」的地方，v0.5.1 一并补齐：

| # | 缺口 | 补齐方式 |
|---|------|----------|
| 1 | 覆盖拟合没排除空心点/弱邻区点（违反 1.1、3.1） | `CoverageFitter.fit` 先用 `AreaBuilder.isValidPoint` 过滤，再拟合；老会话无标记时自动回退全集 |
| 2 | 没有 Douglas–Peucker 抽稀（3.2） | 新增 `core/fitting/PolylineSimplify.kt`，凹包外框按平均精度抽稀去毛刺 |
| 3 | 边缘点没有内缩/降权（3.1） | `AreaBuilder` 成面只用「阈值 + 6dB」的强点；成面后向质心内缩 `平均精度×0.5`（上限 20m） |
| 4 | GPS 50m/3m 门槛写死（2.1/2.2 要求可调） | 设置页「采集与安检」两条滑杆（精度 10–100m、防抖 1–10m），持久化并在建控制器时应用 |
| 5 | 单人模式不能自己标点并导航（第 5 章） | 地图右下新增「标点」按钮 → 点地图落点 → 弹窗「我的标点」→「导航到此」唤起高德/系统地图 |
| 6 | 热力图强/中/弱阈值写死（第 6 章「阈值可配」） | 图层面板新增「强信号阈值」「弱信号阈值」两条滑杆 |

另外三处顺手修：

- 导出图图例补「紫 = 理论∩实测」（原来只画了紫色交集，图例没写）。
- 静默跟踪状态变化除 Logcat 外再落盘 `filesDir/silent_track.log`（需求 10「状态变化写日志」）。
- 多人房间插旗/可疑设备标点自动带上「任务：<当前分配给我的范围备注>」，让标点与任务范围有关联（需求 4.2）。

单测：12 个测试类 / 98 个用例（新增 `PolylineSimplifyTest` 6 例）。
