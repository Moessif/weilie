# 升级到 v1.10 · 操作单（服务器队友执行）

> 适用：线上 v1.8（`/` 显示 `0.1.0`）→ v1.10。
> 预计停机：30–60 秒（重启服务）。
> 前置：能 SSH 到 `47.89.181.85`，有 `sudo`。

## 0. 上线前确认

- [ ] 已通知正在使用协同的队员（重启会断线，客户端会自动重连）
- [ ] 已备份 `data/`（见第 1 步）
- [ ] 已准备随机管理员口令（32 位，例如 `openssl rand -hex 16`）

## 1. 备份

```bash
sudo systemctl stop weilie
sudo cp -a /opt/weilie/weilie-server-all.jar /opt/weilie/weilie-server-all.jar.bak.$(date +%Y%m%d%H%M)
sudo tar czf /opt/weilie/data-backup-$(date +%Y%m%d%H%M).tgz -C /opt/weilie data
ls -lh /opt/weilie/*.bak.* /opt/weilie/data-backup-*.tgz
```

## 2. 上传并替换 jar

```bash
# 本机（仓库/交付包目录）
scp artifact/weilie-server-all.jar root@47.89.181.85:/tmp/weilie-server-all.jar

# 服务器
sudo mv /tmp/weilie-server-all.jar /opt/weilie/weilie-server-all.jar
sudo chmod 644 /opt/weilie/weilie-server-all.jar
```

## 3. 更新 systemd 单元

```bash
sudo vi /etc/systemd/system/weilie.service
```

确认包含这三行（`WEILIE_DATA_DIR` 必须保留）：

```ini
Environment=WEILIE_DATA_DIR=/opt/weilie/data
Environment=WEILIE_ROOM_TTL_DAYS=3
Environment=WEILIE_ADMIN_TOKEN=<32 位随机串>
```

> 不想立刻启用 TTL=3 天？先写成 `WEILIE_ROOM_TTL_DAYS=30`，确认房间清理策略后再改回 3。

```bash
sudo systemctl daemon-reload
sudo systemctl start weilie
sudo systemctl status weilie --no-pager
```

## 4. 验证（逐条打勾）

```bash
# 4.1 版本
curl -s http://47.89.181.85:8080/ | grep -o '"version":"[^"]*"'
# 期望 "version":"1.10.0"

# 4.2 指标
curl -s http://47.89.181.85:8080/metrics | grep -E "weilie_(rooms|online_members|rate_limited)"

# 4.3 房间清单（带口令）
curl -s -H "X-Admin-Token: <口令>" http://47.89.181.85:8080/api/rooms | head -c 200

# 4.4 无口令应被拒
curl -s -o /dev/null -w "%{http_code}\n" http://47.89.181.85:8080/api/rooms
# 期望 403

# 4.5 建房 + 令牌 + 导出鉴权
ROOM=$(curl -s -X POST -H 'Content-Type: application/json' -d '{"name":"v110-check"}' http://47.89.181.85:8080/api/teams)
echo "$ROOM"
# 记下 roomId / joinCode，然后：
# curl -s -X POST -H 'Content-Type: application/json' \
#   -d '{"code":"<joinCode>","userId":"u1","name":"检查","role":"CAPTAIN"}' \
#   http://47.89.181.85:8080/api/teams/<roomId>/token
# 期望返回 token 与 expiresInSec=43200
```

- [ ] `/` 返回 `1.10.0`
- [ ] `/metrics` 正常
- [ ] `/api/rooms` 带口令 200、不带口令 403
- [ ] token 接口返回 43200
- [ ] App（0.21.2）建房、进房、队长划区正常
- [ ] 队长转让给队员后，原队长**看不到「转移」按钮**（需两台设备）

## 5. 清理历史测试房间（可选）

```bash
# 先看清单
curl -s -H "X-Admin-Token: <口令>" http://47.89.181.85:8080/api/rooms | head -c 1000

# 只清 3 天前的空房（安全）
curl -s -X POST -H "X-Admin-Token: <口令>" \
  "http://47.89.181.85:8080/api/admin/purge-rooms?days=3&emptyOnly=true"
# -> {"ok":true,"removed":N,"scanned":M}
```

> `emptyOnly=false` 会连有任务区的房间一起删，慎用。

## 6. 回滚（任一步失败）

```bash
sudo systemctl stop weilie
sudo mv /opt/weilie/weilie-server-all.jar.bak.YYYYMMDDHHMM /opt/weilie/weilie-server-all.jar
sudo systemctl start weilie
curl -s http://47.89.181.85:8080/api/health
```

v1.9/v1.10 新增的 `data/audit.jsonl`、`data/rooms/` 旧版不会读取，可保留。

## 7. 升级后观察 24 小时

```bash
sudo journalctl -u weilie --since "1 hour ago" | grep -iE "错误|error|拒绝|限流" | tail -30
du -sh /opt/weilie/data/audit.jsonl /opt/weilie/data/rooms 2>/dev/null
curl -s http://47.89.181.85:8080/metrics | grep rate_limited
```

异常时先回滚，再排查。
