## 二、构建（只在本机做，服务器不需要 Gradle）

前置：JDK 17、Gradle 8.7（或仓库自带 wrapper）。

```bash
cd server
gradle fatJar --no-daemon
# 产物：server/build/libs/weilie-server-all.jar（约 15.7 MB）
```

本包已带构建好的 `artifact/weilie-server-all.jar`，可直接用；如需自行构建，按上面命令即可。

> `fatJar` 是自定义任务（`build.gradle.kts` 内），不要用 `gradle build` 的普通 jar，它没有依赖。

## 三、首次安装（新机器）

```bash
# 1) 运行时与目录
sudo apt-get update
sudo apt-get install -y openjdk-21-jre-headless
sudo mkdir -p /opt/weilie/data
sudo touch /var/log/weilie.log

# 2) 上传 jar 与 systemd 单元
#    本机：scp artifact/weilie-server-all.jar root@<IP>:/opt/weilie/weilie-server-all.jar
#    本机：scp deploy/weilie.service root@<IP>:/etc/systemd/system/weilie.service

# 3) 验真密钥（首次必须生成并离机备份；丢失则历史验证码全部失效）
head -c 32 /dev/urandom | sudo tee /opt/weilie/data/hmac.secret > /dev/null
sudo chmod 600 /opt/weilie/data/hmac.secret

# 4) 启动
sudo systemctl daemon-reload
sudo systemctl enable --now weilie.service
sudo systemctl status weilie --no-pager

# 5) 验证
curl http://127.0.0.1:8080/api/health
```

## 四、从 v1.2 升级到 v1.3（本次场景）

### 1. 升级前备份（必须）

```bash
cd /opt/weilie
sudo systemctl stop weilie
sudo cp -a weilie-server-all.jar weilie-server-all.jar.bak.$(date +%Y%m%d%H%M)
sudo tar czf data-backup-$(date +%Y%m%d%H%M).tgz -C /opt/weilie data
sudo systemctl start weilie

# 备份文件拉回本地留存
# scp root@47.89.181.85:/opt/weilie/data-backup-*.tgz ./
```

### 2. 上传并替换 jar

```bash
# 本机
scp artifact/weilie-server-all.jar root@47.89.181.85:/tmp/weilie-server-new.jar

# 服务器
sudo mv /tmp/weilie-server-new.jar /opt/weilie/weilie-server-all.jar
sudo chmod 644 /opt/weilie/weilie-server-all.jar
sudo systemctl restart weilie
sudo systemctl status weilie --no-pager
sudo tail -n 50 /var/log/weilie.log
```

### 3. 验证

```bash
curl -s http://47.89.181.85:8080/api/health
curl -s http://47.89.181.85:8080/metrics | head -20
curl -s http://47.89.181.85:8080/api/rooms
```

### 4. 交付后观察 24 小时

## 五、systemd 单元（与线上一致）

```ini
[Unit]
Description=Weilie backend (Ktor)
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
WorkingDirectory=/opt/weilie
Environment=WEILIE_DATA_DIR=/opt/weilie/data
Environment=WEILIE_ROOM_TTL_DAYS=7
ExecStart=/usr/bin/java -Xms64m -Xmx320m -jar /opt/weilie/weilie-server-all.jar
Restart=always
RestartSec=3
StandardOutput=append:/var/log/weilie.log
StandardError=append:/var/log/weilie.log

[Install]
WantedBy=multi-user.target
```

修改单元后：`sudo systemctl daemon-reload && sudo systemctl restart weilie`。

内存建议：日常 12 人/房间、几十个房间时 `-Xmx320m` 足够；若长时间不清理房间，可提高到 `-Xmx512m`。

## 六、环境变量

| 变量 | 默认 | 建议线上值 | 说明 |
|---|---|---|---|
| `WEILIE_DATA_DIR` | `./data` | `/opt/weilie/data` | 数据目录 |
| `WEILIE_ROOM_TTL_DAYS` | `7` | `7` | 房间无活动回收天数（1–365） |
| `OPENCELLID_KEY` | 空 | 按需 | 基站库代理密钥；不配则基站库接口降级 |
| `WEILIE_HMAC_SECRET` | 空 | 不配 | 照片验签密钥；优先于 `data/hmac.secret` |

## 七、回滚

```bash
sudo systemctl stop weilie
sudo mv /opt/weilie/weilie-server-all.jar.bak.YYYYMMDDHHMM /opt/weilie/weilie-server-all.jar
sudo systemctl start weilie
curl -s http://127.0.0.1:8080/api/health
```

v1.3 新增的 `data/audit.jsonl`、`data/rooms/` 旧版不会读取，可保留；
若必须完全回到旧状态，停服后 `sudo rm -rf /opt/weilie/data/rooms /opt/weilie/data/audit.jsonl`。

## 八、Docker 备选（与 systemd 二选一）

仓库自带 `Dockerfile` / `docker-compose.yml`：

```bash
cd server
docker compose up -d --build
docker logs -f weilie-server
```

注意：`./data` 需映射到宿主机（compose 已配置），否则容器重建会丢快照与照片登记。
