# v0.17.0：团队导出（全队 / 本人）

## 已完成
团队任务面板新增「导出（全队 / 本人）」，打开后是两项：

| 分组 | 格式 | 数据来源 |
|---|---|---|
| 全队 | GeoJSON / KML / CSV | 服务端 `GET /api/teams/{roomId}/export?code=&format=`（v1.3 提供） |
| 本人 | GeoJSON / KML / CSV | 本机样本 + 本人 `CoverageFitter` 拟合（含洞/面积/引擎） |

实现：
- `ui/team/TeamExport.kt`：本地导出复用 `CsvExporter/GeoJsonExporter/KmlExporter`；全队导出走 HTTP，
  文件写入 `cache/team-export/`，再交给 `shareFile` 弹系统分享；
- 全队导出需要 `AppGraph.lastJoinCode`（队伍码），缺失时提示「缺少队伍码，无法导出全队数据」；
- 导出失败（服务端未升级 / 403 / 网络）都会 toast 具体原因。
