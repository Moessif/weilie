# v0.12.4 — Shizuku 邻区增强（无需 root）

> 版本：`versionCode 30` / `versionName 0.12.4`  
> 背景：非 root、甚至非系统应用的手机，Android 10 起对 `getAllCellInfo()` 只返回驻留小区；
> 部分 ROM（HyperOS / ColorOS / OriginOS 等）还会再过滤一层。结果就是「附近还有 0 个基站」，
> 邻区命中、邻区 RSRP、邻区统计全部落空。装 Shizuku 之后可以绕开这个限制。

## 一、能拿到什么

Shizuku 常驻的 `shell`（uid 2000）进程持有 `READ_PRIVILEGED_PHONE_STATE` 等特权权限。
围猎授权后，每 **2 秒**以 shell 身份执行一次：

```sh
dumpsys telephony.registry
```

解析其中的 `mCellInfo=[CellInfoLte:{...}, CellInfoNr:{...}]`，得到：

| 字段 | 来源 | 用途 |
| --- | --- | --- |
| `mCi` / `mNci` | CellIdentityLte / CellIdentityNr | 邻区编号（LTE 28bit / NR 36bit） |
| `mPci` | 同上 | 邻区 PCI 指纹匹配 |
| `mEarfcn` / `mNrArfcn` | 同上 | 频段（B3 / N41 …） |
| `mMcc` / `mMnc` | 同上 | 运营商过滤，避免混入别家邻区 |
| `rsrp` / `rsrq` / `rssnr` / `ssRsrp` / `ssRsrq` / `ssSinr` | CellSignalStrength* | 邻区强度，「邻区命中」判定与专家面板 |
| `mRegistered` | CellInfo | 区分驻留 / 邻区 |

> 注：Android 用 `2147483647 / -2147483648` 表示「无测量值」，解析时统一转成「缺失」，
> 不会污染统计。

## 二、授权流程（用户侧）

1. 手机装 [Shizuku](https://shizuku.rikka.app/)（应用商店或 GitHub Releases）；
2. 打开 Shizuku → 按它引导启动服务（无线调试或 USB 授权，重启后无线模式需重新启动）；
3. 打开围猎 → 设置 → **邻区增强（Shizuku）** → 状态应为「未授权」→ 点「申请授权」；
4. Shizuku 弹出授权框 → 允许；
5. 状态变「已授权」，之后采集会自动补全邻区（数据栏「附近还有 N 个基站」、邻区命中、静默跟踪都会跟着生效）。

未安装 / 服务未运行 / 未授权时，按钮会分别显示「去安装」「打开 Shizuku」「申请授权」，
采集层自动回退系统 API，功能与旧版完全一致，不会报错也不会崩。

### 两个技术要点

1. **Shizuku 13 把 `Shizuku.newProcess` 设为 private**：官方推荐 `ShizukuBinderWrapper` + 系统服务，
   但本项目只需跑一条 shell 命令，故用反射调用该私有静态方法（`exec()`），失败即返回 null，
   不影响任何现有功能。
2. **NCI 不能按 Int 解析**：NCI 是 36bit（如 `5677244420` > `Int.MAX_VALUE`），
   最早写成 `toIntOrNull()` 时静默变 null，单测直接把它抓了出来（`parses_nr_neighbor_nci_and_band`）。

## 四、测试

新增 `app/src/test/java/com/gakj/weilie/core/telephony/ShizukuCellsTest.kt`（8 例）：

- 驻留 LTE 小区字段全解析（ci / pci / earfcn / tac / mcc-mnc / rsrp / rsrq / sinr / band=3）；
- LTE 邻区解析（含 Int.MAX_VALUE 的 `ta` 不影响）；
- NR 邻区：`mNci=5677244420`、PCI 23、NCI 频段 N41；
- 缺失测量值（`2147483647`）→ null；
- `toPairs` 去重 + 按 RSRP 降序；
- 重复 (rat, ci) 只留第一条；
- 空文本 / 乱码 / 括号不闭合 → 空列表（不会死循环）；
- band 推导（B1 / N78 / 2G 返回 null）。

全仓：**24 个测试类 / 183 用例 / 0 失败**。
