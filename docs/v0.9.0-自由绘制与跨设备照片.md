## 一、本轮修的三件事

### 1. 多人模式「自由绘制任务范围」改为真正的画图交互

用户原话：

> 多人模式的那个自由绘制任务范围，我觉得可以弄成单指画范围（像画画一样）然后双指是拖动，下面有确认或者重画、撤销

实现（地图引擎层 `ui/map/BaiduMapCanvas.kt`）：

- `MapCanvas(...)` 新增参数 `drawMode: Boolean`、`onDrawPoint: ((Double, Double) -> Unit)?`，`BaiduMapCanvas` 与离线的 `CanvasMap` 都接受同样签名。
- 进入绘制模式后，在地图上挂 `BaiduMap.OnMapTouchListener`：
  - **单指按住拖动**：手指移动每超过 14 px（屏幕像素）就取一个点，`map.projection.fromScreenLocation` → `BaiduCoords.bd09ToWgs84` 得到经纬度回调，连续成线（像画画）。
  - **双指拖动**：取两指质心，按质心位移调用 `camera.panBy(...)` 平移地图，不产生顶点。
  - 绘制期间 `uiSettings.setScrollGesturesEnabled(false)` / `setZoomGesturesEnabled(false)`，避免「边画边漂」。
  - 绘制中轻点地图也会补一个顶点（`onTapLatLon` 的 drawMode 分支），方便点画。
- 底部操作条（`ui/team/TeamRoomScreen.kt`）：`撤销一点` / `重画` / `取消` / `完成`，上行提示「单指按住拖动画范围（双指拖动地图）· 已 N 个点」。
- 顶点 ≥3 时地图实时显示半透明多边形预览；点 `完成` 弹「分配给谁」（全队 / 指定队员），落成 `WsMsg.Zone(kind=POLYGON, replace=true)` 下发，任务面板里可见「自由绘制任务区（多边形 N 顶点）」。

真机验证（REDMI K80 Pro，1080×2400）：

- 连续三段滑动 → 底部计数 0 → 58 → 61 → **77 个点**，地图上实时出现青色多边形；
- `撤销一点` / `取消` 均生效（取消后操作条消失、预览清除）；
- `完成` → 「分配给谁（自由绘制范围（77 个顶点）将以多边形任务区下发）」→ 选「全队（不指定）」 → 操作条收起，地图保留任务区多边形；
- 打开「任务」面板，列表第一条即「自由绘制任务区（多边形 77 顶点）」✅

### 2. 跨设备打开取证照片：不再显示「未找到」

原因：照片索引只在本机 `PhotoStore`，队友那台设备没有这条记录；房间协议里的标点只带了本机 `photoId`，没有验证码，服务端也没法按标点反查。

修复（协议 + 服务端 + 客户端）：

- 协议两端（`core/sync/Protocol.kt`、`weilie/server/.../Protocol.kt`）：`Marker` 增加 `photoCode`，`PhotoRef` 增加 `code`。
- 拍照回传：`TeamRoomScreen` 在 `room.photo(...)` 之前先调用 `PhotoVerifier.register(file, rec)` 拿到 `(code, sig)` 一并广播；服务端 `RoomWs` 落标点时写入 `photoCode`。
- 打开标点：`PhotoDetailSheet(photoId, remoteCode = "")` 本机查不到记录但有 `remoteCode` 时，改走 `PhotoVerifier.lookup(code)`（`GET /api/photo/verify?code=...`），展示「远程取证记录」卡片：验证码 / 登记时间 / 拍摄时间 / 坐标 / 设备类型 / 备注 / 哈希前缀 / 服务器签名有效性，并注明「照片原件在拍摄设备上」。
- 服务端接口本轮无需新增（`PhotoRegistry` 已有按 code 的查询与 `/v/{code}` 网页验真），本次只是重新打了 fat jar 并部署，让 `photoCode` 字段生效。

### 3. 单人模式删除标点后地图上仍存在

原因：`markers` 原先是 `remember { mutableStateListOf<WsMsg.Marker>() }`，Compose 对「列表内容变化」在只把列表当参数往下传时不一定触发 `MapCanvas` 重组，于是删掉的标点继续画在地图上。

修复：`SingleMapScreen` 改为不可变列表状态 `var markers by remember { mutableStateOf<List<WsMsg.Marker>>(emptyList()) }`，新增一律 `markers = markers + ...`，删除用 `markers = markers.filterNot { ... }`（优先按 `id` 匹配，退回按 `ts + lat + lon` 匹配）。

真机验证：插旗 → 详情页「删除这个标点」→ 弹层关闭，地图上该旗子**立即消失** ✅

### 4. 顺带：采样点巨大圆斑（v0.8.1 遗留）

v0.8.1 已把采样点从「按米半径的 Circle」改成**固定像素 Marker 图标**（主区命中 26 px 实心、邻区命中 28 px 彩色实心、脱离 20 px 空心环），图标不随缩放变化，真机验证不再出现大圆斑。
