# v0.6.2 历史记录删除

> 版本：`versionCode 17` / `versionName "0.6.2"`（2026-11-09）
> 需求来源：用户反馈「点开全部记录后只能查看不能删除」

## 一、加了什么

入口不变：首页「全部记录」→ 历史记录页。

| 能力 | 操作方式 | 说明 |
| --- | --- | --- |
| 长按删除 | 长按任意记录卡片 | 直接弹确认框，显示这条记录的采样点数 |
| 选择删除 | 右上「管理」→ 点卡片多选 → 底部「删除选中（N）」 | 右上「全选 / 取消全选」，选择模式下系统返回键先退出选择 |
| 全部删除 | 选择模式底部「全部删除」 | 确认框显示总条数与总采样点 |

- 删除是**真删**：`sessions/{taskId}/` 整个目录递归删除（`manifest.json` + `samples.jsonl` + 该会话的导出文件）。
- 确认框统一提示「删除后无法恢复」，确认按钮用危险色。
- 选择模式下选中卡片有主色描边 + 勾选图标，避免小屏误判。

## 二、实现位置

| 文件 | 改动 |
| --- | --- |
| `core/store/SessionStore.kt` | 新增 `deleteSession(taskId): Boolean`、`deleteAllSessions(): Int` |
| `ui/theme/Glass.kt` | `GlassCard` 新增 `onLongClick`（`combinedClickable`），未传时行为与原来完全一致 |
| `ui/history/HistoryScreen.kt` | 重写：选择模式、底部操作条、删除确认框、空列表自动退出选择模式 |

安全性：`deleteSession` 用 `canonicalFile` 校验父目录必须是 `sessions/` 本身，`taskId` 里带 `../` 也无法删到别处。

## 三、验证

- `:app:testDebugUnitTest` → 15 个测试类 **121 用例全绿**（删除是纯文件操作，未另加单测；风险点在 UI 状态机）。
- 模拟器实测（AVD `weilie_test`，Android 15 / 1080×2400）四条路径全部通过：
  1. 长按第一条 → 「删除这条记录？/ 将删除 1 条记录、共 1 个采样点」→ 删除后列表 6 → 5 条，示例会话 `team-09c06fa8b8fc` 消失；
  2. 「管理」→ 标题变「已选 0 项」、卡片出现圆圈、底部出现「全部删除 / 删除选中」；
  3. 「全选」→「已选 5 项」「删除选中（5）」→ 弹「删除选中的 5 条记录？共 5 个采样点」；点取消不误删、仍在选择模式；
  4. 「全部删除」→「删除全部记录？」→ 确认后列表变空态「还没有走测记录」，设备上 `sessions/` 目录已空。
- 产物：`dist/weilie-v0.6.2-debug.apk`（80,880,551 字节，sha256 `8F669CBAEFE9936771E22D59E347D5F0A0694F9720EFBD82C5E3550CF08BB4FD`）。

## 四、已知取舍

- 删除只删本机采集数据，**不影响**已上传/已分享的导出文件与在线验真记录（服务端照片索引不受影响）。
- 没有做「撤销删除」（回收站），确认框已二次确认；如后续需要可把目录先改名到 `sessions/.trash/` 再延迟清理。
