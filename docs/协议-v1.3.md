# 协同协议 v1.3（客户端 ↔ 服务端）

传输：WebSocket 文本帧，JSON，判别字段 `type`。
基础地址：`ws://<host>:8080/ws/room/{roomId}?userId=&name=&role=`。
本版**只新增字段与消息，未改已有语义**；旧客户端可正常连接。

## 一、消息总表

| type | 方向 | 用途 | v1.3 变化 |
|---|---|---|---|
| `hello` | C→S | 注册成员、声明角色 | — |
| `loc` | C→S→C | 位置（2s 节流） | — |
| `sample` | C→S→C | 采样心跳（10s） | 服务端落盘 |
| `chat` | C→S→C | 聊天 | 服务端限流 30/min |
| `photo` | C→S→C | 照片引用（落成标点） | 服务端限流 |
| `zone` | C→S→C | 任务区下发/重划 | 新增 `id`、`deleted` |
| `zoneDelete` | C→S→C | 删除任务区 | 改为软删除 |
| `promote` | C→S→C | 队长转让 | 审计 |
| `promoteRequest` | C→S | 队员申请接任 | 审计 |
| `promoteDecline` | C→S | 队长拒绝接任 | 审计 |
| `marker` / `markerDelete` | C→S→C | 标点增删 | 审计 + 限流 |
| `audioStart`/`Chunk`/`Stop` | C→S→C | 语音转发 | 帧上限 96k 字符、600/min |
| `ping` / `pong` | C→S / S→C | 心跳 | — |
| `state` | S→C | 权威房间快照 | 新增 `zoneStats`、区域软删除 |
| `chatEcho` | S→C | 聊天回显 | — |
| `photoAck` | S→C | 照片回执 | — |
| `bye` | S→C | 成员离线/被拒 | — |

## 二、v1.3 新增字段

### `zone` / `state.zones[]`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | String | 服务端分配（`z-xxxx`），删除/统计用；旧客户端为空 |
| `deleted` | Boolean | 软删除标记；`state.zones` 只下发未删除项 |

### `state.zoneStats[]`（v1.2 引入，v1.3 保持）

```json
{"id":"z-abc","covered":42,"total":120,"ratio":0.35,"samples":318}
```

`ratio = covered / total`，网格 20 m；只统计 `assignees`（为空则全队）。

## 四、兼容性矩阵

| 客户端 | 服务端 v1.2 | 服务端 v1.3 |
|---|---|---|
| 0.14.x / 0.15.0 | 正常；无覆盖率/软删除 | 正常；忽略新字段 |
| 0.15.1（本版） | 新按钮被忽略（无反应），不断连 | 全部功能可用 |

> 旧服务端对未知 type 的处理是 `runCatching` 后 `continue`，**不会断开连接**。

## 五、错误与边界

| 场景 | 服务端行为 |
|---|---|
| 非队长下发 zone | 忽略并记 warning |
| 删除他人任务区且非队长 | 忽略 |
| 观战者发 loc/sample | 允许写入成员视图（客户端已不发） |
| 超限流 | 丢弃该帧（WS）或 429（HTTP） |
| 未知 type | 忽略 |
| 超过 12 人 | `bye` + 关闭连接 |
| 音频帧 >96k 字符 | 丢弃 + warning |
| 房间不存在 | WS 直接关闭（客户端重试） |

## 七、v1.8 追加（全队合并覆盖）

`state` 新增字段：

```json
{"teamSamples":[
  {"userId":"u-1001","lat":39.9,"lon":116.3,"rsrp":-95,"onTarget":true,"ts":1731600000000}
]}
```

- 服务端把房间内所有采样**降采样到 ≤1500 点**后随 state 下发（每 10 个采样广播一次）；
- 客户端用它拟合「全队覆盖」；老服务端不返回该字段时客户端只显示本人覆盖；
- 只读字段，客户端不上报。
## 八、v1.10 追加（任务区转移与清空）

| type | 方向 | 说明 |
|---|---|---|
| `zoneTransferRequest` | C→S→C | 发起转移（归属人或队长），仅转发给目标 |
| `zoneTransferAccept` | C→S→C | 目标接受，`assignees` 变为该成员 |
| `zoneTransferDecline` | C→S | 目标拒绝，服务端通知发起人 |
| `zoneClear` | C→S→C | 队长清空全部任务区（软删除） |

`zone` / `state.zones[]` 新增 `pendingTransferTo`（待确认目标，空=无）。旧客户端忽略新字段。
