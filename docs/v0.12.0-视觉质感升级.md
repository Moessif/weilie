# v0.12.0 视觉质感升级

本轮不新增业务能力，也不改动服务端协议，只做一件事：**把整个 App 的视觉语言收敛成一套系统**，并逐屏核对。

## 一、为什么改

v0.11.2 之前的功能是一版一版加出来的，页面各写各的：

- 圆角有 10/12/14/16/18/20/26 七种，按钮有渐变胶囊、玻璃胶囊、文字按钮三种；
- 面板块套块、玻璃叠玻璃，地图页数据栏半透明，底图文字会透出来；
- 主色是青色，辅助色却是紫罗兰；地图上的方向箭头也是紫罗兰；
- 首页雷达占屏中央，标题到雷达之间空掉约 500px；登录页底部半屏空白；
- 深浅色只留深色（v0.11.0 已固定），但系统状态栏在浅底图上仍是白图标。

## 二、设计系统（新增 `ui/theme/Tokens.kt`）

| 令牌 | 内容 |
| --- | --- |
| `Space` | x1=4 x2=8 x3=12 x4=16 x5=20 x6=24 x8=32；screenH=20（页面左右边距）、card=16、row=14 |
| `Radius` | sm=10 md=14 lg=20 xl=26 pill=999，并带对应的 `Shape` |
| `Hairline` | `Modifier.hairline(shape, strong)` / `hairlineTop(...)`，1dp 发丝描边 |
| `Rhythm` | tight=12 normal=20 section=32 |

配套重写：

- **调色板**：底色压到 `#060910 / #0B1120 / #121A2C`，玻璃一律 6–12% 白、描边 20% 白；辅助色由紫罗兰 `#A78BFA` 改为同族青绿 `#5EEAD4`；主题色里的「靛紫/品红」预设换成「湖蓝/松绿」。
- **字阶**：displaySmall 34、headlineMedium 27、titleLarge 19、titleMedium 15.5、bodyLarge 15/22、bodyMedium 13.5/20、bodySmall 12/17、labelSmall 10.5，统一负字距。
- **组件**：`GlassCard`（按压 0.985）、`GlowButton`（实心主色胶囊，**禁用态改为中性灰底 + 发丝描边**，不再是亮青块）、新增 `OutlineButton`（发丝描边胶囊）、`GlassIconButton` 48dp、`StatChip` 纵向布局、`SectionHeader` 去掉装饰色条、新增 `Eyebrow`。

## 五、已知取舍

- 会话详情回放卡的底图在模拟器上依赖百度瓦片，网络不佳时会显示白底；真机有瓦片时正常。
- 历史页只有一条会话时，卡片下方仍留白。
- Material3 `Slider` 拇指是竖条样式（系统默认），如需圆点需自定义 thumb。
- 服务端无需更新：本轮没有协议与接口改动。

## 六、复核建议

1. 真机深色环境下看地图页顶部数据栏与状态栏是否可读；
2. 打开相机，确认取证类型 chips 两行、「GPS 定位中…」只在无定位时出现；
3. 多人协同页确认三条玩法说明与底部按钮不重叠；
4. 设置页切换主题色，确认没有紫罗兰色相。
