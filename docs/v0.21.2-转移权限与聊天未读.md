# v0.21.2：仅队长可转移任务 + 聊天未读提示

## 一、转移权限修正（Bug）
**问题**：队长转让后，原队长（已降为队员）仍能转移任务。
**原因**：v1.10 的权限是「任务归属人 **或** 队长」，归属人降级后仍满足。
**修复**：
- 服务端：`zoneTransferRequest` 只接受 **现任队长**（`senderRole == CAPTAIN`）且 `by == 发送者`；
- 客户端：任务列表「转移」按钮仅 `myRole == CAPTAIN` 时显示；
- 队长转让时：服务端会清空所有待确认转移，避免旧队长遗留请求在转让后生效。

## 二、聊天未读提示
- 右侧「聊天」按钮右上角显示红点 + 未读数（>99 显示 99+）；
- 未读按**到达顺序计数**（不比较时间戳，避免设备/服务端时钟偏差）；
- 首次进房的历史消息不算未读；打开聊天面板即清零。

## 四、风险
- 行为变化：队员（非队长）将看不到「转移」按钮；若需要“任务归属人也能转移”，需另行放开；
- 队长转让会取消所有待确认转移，需重新发起；
- 聊天未读仅在本机计数，重进房间后从零开始（历史不计未读）。
