# v0.14.1：多人协同「拍照 / 标记」先选位置（当前位置 / 自定义位置）

## 需求
队长（以及队员）点「拍照」或「标记」时，先弹出两个选项：
**当前位置** / **自定义位置（点地图）**；自定义位置的照片必须在水印上标注「手动选点（非 GPS）」。

## 改动
### 1. TeamRoomScreen
- 底部「标记」不再用下拉菜单，改为 `ModalBottomSheet`：
  - 类型 chips：普通旗标 / 可疑设备 / 取证；
  - 位置两项：当前位置 / 自定义位置（点地图）。
- 底部「拍照」改为 `ModalBottomSheet`：当前位置 / 自定义位置。
- 「当前位置」：
  - 旗标/可疑设备 → 直接进入原有的命名 + 可见范围对话框（`newMarkerAt`）；
  - 取证 → 直接打开相机，`manualPhoto = false`；
  - 无定位时该项置灰并提示「暂无定位」。
- 「自定义位置」：进入原有 `placeMode` 点图流程；取证时 `manualPhoto = true`。
- 所有角色（队长/队员/观战除外）都可用。

### 2. 相机水印（强制标注）
- `PhotoCameraScreen` 新增参数 `manualLocation: Boolean = false`；
- `WatermarkSpec.manualLocation` + 常量 `位置：手动选点（非 GPS）`；
- 该行同时出现在：屏幕实时水印、烧进照片、`PhotoRecord.lines`（详情页可见）；
- 屏幕与烧图使用同一份 `spec`，保证三处一致。
