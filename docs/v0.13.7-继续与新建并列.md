# v0.13.7：首页「继续上次走测」支持新建

## 问题
首页的会话卡整块可点，只能进入 `map/{id}` 继续；「新建」入口只有底部停靠栏的
「单人走测」，不显眼。且已结束的会话被继续时没有任何提示，新样本会追加进旧会话。

## 改动（仅 `HomeScreen.kt`）
- 卡片拆成「信息区 + 动作区」两行：
  - 信息区：标题、样本数/日期、状态徽标；
  - 动作区：左「继续上次 / 继续追加」、右「+ 新建」，各占一半宽度（pill 按钮）；
- 已结束会话（`endedAtEpochMs != null`）：
  - 标题后显示「已完成」徽标；
  - 副标题改为「N 个样本 · 继续会追加到该会话」；
  - 左按钮文案改为「继续追加」；
- 未结束会话保持「继续上次 + 日期」；
- 点击区域拆分：两个按钮各自 `clickable`，卡片外层不再可点（避免外层吞点击）。

## 验证
| 场景 | 结果 |
|---|---|
| 360×800dp，已完成会话 | 「已完成」徽标 + 「继续追加 / 新建」双按钮 ✅ |
| 点「新建」 | 进入「新建走测任务」页 ✅ |
| 点「继续追加」 | 进入地图页（继续该会话）✅ |
| 320×568dp | 双按钮并排，不换行、不重叠 ✅ |
| 单测 | 210 / 210 |
