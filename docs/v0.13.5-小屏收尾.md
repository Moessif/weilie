# v0.13.5：图层面板与小屏收尾

> 基线 v0.13.4。目标：把「320×568dp 下图层面板打不开」彻底查清并修掉，同时验收 AI / 多人 / 通知卡。

## 一、问题定性（此前误判的纠正）

1. 早期判断「点击没到按钮」是**错的**：该 ROM 屏蔽了 `Log.d`，调试日志看不到；
2. 升到 `Log.w` 后实测：`root down x=80 y=752` → `tap 图层 -> showLayers=true`，点击正常；
3. 真实原因是**面板位置算错**：`topChromePx=767px`（数据栏 384dp），面板从 392dp 开始、
   高度被夹到 220dp，底部 612dp 超出 568dp 屏；标题被工具箱按钮压住。

## 二、改动

| # | 文件 | 改动 |
|---|---|---|
| 1 | `SingleMapScreen.kt` | 面板位置/高度改用窗口像素计算：`top=min(数据栏底, 屏高×42%)`，小屏固定 `屏高×26%`；高度 `屏高−top−92dp`，夹 140–460dp |
| 2 | `MapDataBar.kt` | 新增 `compact` 参数（由调用方按 `maxH/density` 判断，避免 `wm size` 覆盖时 `LocalConfiguration` 失真）；精简时隐藏 SIM 明细、邻区行、置信度行 |
| 3 | `SingleMapScreen.kt` | 传入 `compact = maxH / density < 640` |
| 4 | `HomeScreen.kt` | 通知卡下移（`top 66dp → 132dp`），不再遮住问候语 |
| 5 | 全部 | 删除临时 `WeilieUI` 调试日志 |
