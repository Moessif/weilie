## 二、顺带修复的 3 个真 Bug

1. **「附近还有 0 个基站」但实际有邻区**
   - 根因：`SingleMapScreen` 用 `snapshot.neighbors.mapNotNull { it.ciHex }` 取邻区，2G/3G 及部分 5G 邻区 `ciHex` 为 null 被全部丢弃。
   - 修复：改为 `ci ?: "PCI $pci" ?: "${rat.displayName} 小区"` 兜底。
   - 真机结果：显示「附近还有 8 个基站 · 点按查看」。

2. **地图出现巨大蓝色实心圆斑**
   - 根因：`circleDot/circleRing` 用「像素 × 当前米/像素」算半径，而地图刚加载时 `mapStatus.zoom == 0`，半径被放大上百万倍；且渲染指纹 `key` 不含 zoom，缩放落定后不会重建覆盖物，圆斑一直留着。
   - 修复：`metersPerPixelAt` 对 `zoom < 6` 兜底为 16；`render` 的 `key` 末尾追加当前 zoom（取整），缩放落定后重建。
   - 真机结果：蓝斑消失。

3. **继续历史任务时「追踪目标 NCI -- 未设目标」**
   - 根因：`AppGraph.fallbackTask()` 从 `manifest.json` 恢复任务时只把 `targetRawInput` 塞回 `TargetCell`，没有重新解析，导致 eci/nci/lac/经纬度等字段全为 null，`unifiedCi()` 为空 → 命中判定永远 false。
   - 修复：`TaskInputParser.parse(rawInput).target` 优先，解析失败才退回旧兜底。
   - 状态：代码完成，待真机复测（设备已断开）。
