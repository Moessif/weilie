# v0.13.1 变更说明（基于 v0.13.0 源码）

> 基线：`围猎-源码-v0.13.0.zip`（解压于 `围猎\修改\weilie-v0.13.0-source`）
> 本次只做**算法可证伪性**与**置信度语义**两项，不触碰 UI 结构、不动存储格式。

## 一、本期做了什么

### 1. 新增：边界精度评估器（对应 P0-1）

| 文件 | 说明 |
|---|---|
| `core/eval/BoundaryEvaluator.kt`（新） | 纯 JVM，输入真值多边形 + 实测多边形，输出 4 个指标 |
| `core/eval/BoundaryEvaluatorTest.kt`（新） | 4 个用例：完全重合、平移 10 m、三角形截半、退化输入 |

指标定义：

| 指标 | 含义 | 怎么用 |
|---|---|---|
| `iou` | 交并比（2 m 网格采样近似，凹多边形也适用） | `0.7` 以上可认为边界基本吻合 |
| `areaBias` | `(实测面积 − 真值面积) / 真值面积` | 正数=偏大；`±0.2` 以内可接受 |
| `medianOffsetM` | 实测每个顶点到真值边界距离的中位数 | 直接读"边界平均差了几米" |
| `hausdorffApproxM` | 双向最大最小距离（顶点采样近似） | 看最坏情况 |

> 说明：Hausdorff 是顶点采样近似，不是严格连续曲线 Hausdorff，报告里请按"近似"表述。

**验收基线（已用 Python 等价复算校验）**：

```
真值 100×100 m 正方形 vs 整体平移 10 m 的实测：
  IoU = 0.6807（理论 0.681）  ✅
  面积偏差 = 0%                ✅
  边界偏移中位数 ≈ 10 m        ✅
```

### 2. 重构：置信度改为短板模型（对应 P0-4）

| 文件 | 说明 |
|---|---|
| `core/fitting/ConfidenceModel.kt`（新） | 把置信度计算从 `CoverageFitter` 抽出，纯函数、可单测 |
| `core/fitting/ConfidenceModelTest.kt`（新） | 5 个用例：直线、绕圈、少点、单时段、与旧公式对比 |
| `core/fitting/CoverageFitter.kt`（改） | 计算时段覆盖 + 调用 `ConfidenceModel`；`Confidence` 增加 `timeCoverage`、`reasons` 两个字段（带默认值，旧调用点不受影响） |
| `ui/map/SingleMapScreen.kt`（改 1 行） | 置信度文案追加一条短板原因，如「中 45分 · 只覆盖 6/16 个方向」 |

公式变化：

```
旧：score = (样本量因子 × 0.5 + 方向覆盖 × 0.5) × 100
新：score = 100 × min(样本量因子, 方向覆盖, 时段覆盖)
```

新增「时段覆盖」：把会话时长三等分，统计其中**有样本**的段数 / 3；
会话总时长 < 60 s 时按满分处理（短测无法判断时段，避免误判）。

**行为差异示例**（已用 Python 复算）：

| 场景 | 旧分 | 新分 | 档位 |
|---|---|---|---|
| 200 点、只管 4/16 方向 | 62 | **25** | 中 → **低** |
| 120 点、16 方向、三个时段 | 100 | 100 | 高 |
| 5 点、3 方向、1 个时段 | 4 | **4** | 低 |

## 二、两处需要更正原计划的地方

### ① P0-3（卡尔曼噪声自适应）**代码里已经是对的**

原计划写「`r` 固定 1.0」。实际源码是：

```kotlin
private val kalmanR: Double = 1.0,             // 系数
...
val r = (kalmanR * acc * acc).coerceAtLeast(1.0)   // R = 系数 × accuracy²
```

也就是说，**观测噪声已经随定位精度平方缩放**，与"应改成 accuracy²"的目标一致。
报告里"测量噪声 r=1.0"的表述容易被误解为常量，建议改写成
「R = accuracy²（系数 1.0）」。**本期不改这段代码**，避免无谓回归。

### ② P0-2（双引擎自动选优）与 P0-5（哈希链）**未包含在本期**

| 项 | 未做的原因 | 建议版本 |
|---|---|---|
| 双引擎自动选优 | 需要改 `CoverageFitter` 的输出结构（新增 engine/reason/unstable）并接 UI；在没有编译环境的情况下改主拟合流程风险过高 | v0.13.2 |
| 样本哈希链 | 要改 `SessionStore` 的写入、读取与导出三处，且必须兼容旧会话；属于存储层改造，应先补回归用例再动 | v0.13.2 |
