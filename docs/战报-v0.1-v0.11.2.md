## 五、战果清单

### 功能

- 单人覆盖实测：编号解析（ECI/NCI/习惯写法）、打点三态、GPS 双安检、CV 卡尔曼、凹包/模拟区域两种成面、等值线、置信度
- 地图能力：百度底图、卫星、轨迹、基站四种图层；热力图；理论覆盖区（全向/扇形/TA 环带）；理论∩实测
- 多人协同：建房/扫码/队伍码、矩形/圆形/基站扇形/自由绘制四种划区、标点命名与可见性、队员定位、队长转让、观战
- 取证与验真：微信式水印相机、5 类取证对象（地图 emoji 区分）、SHA-256 + HMAC 签名、8 位验证码、网页验真、跨设备远程记录
- 静默跟踪：前台服务、三种震动节奏、强度可调、状态日志
- 导出：CSV / GeoJSON / KML、带百度底图的轨迹图
- 其他：培训模式、AI 助手、历史记录管理、深色主题 + 10 套强调色、参数说明气泡

### 修过的典型硬仗

1. 百度地图 `map.clear()` 与新增覆盖物竞态 → 自记账 remove
2. 覆盖物半径按 zoom=0 换算 → 进图巨点（v0.11.2 彻底修）
3. Compose Constraints 262143px 上限 → 高密度屏闪退（v0.5.2）
4. HyperOS 按卡取小区混入别家 PLMN → 运营商二次过滤（v0.8.0）
5. 双指手势逐帧累加导致地图飘 → 起点锚定 + 投影实测米/像素（v0.11.1）
6. 飞点把凸包撑到城市尺度 → TrackSanity 统一剔除（v0.11.2）
