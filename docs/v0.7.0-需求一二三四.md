## 一、新建任务页

### 1. 参数检验：不合规不让创建

以前随便输一串数字都能建任务，现在先过一道“规格式检查”，不通过就红字说明原因、按钮变灰。

校验规则（`core\parsing\TaskInputParser.kt` 的 `validate(raw)`）：

| 格式 | 规则 |
| --- | --- |
| NCI（5G 小区编号，36 位） | 必须 > 0 且 ≤ `0xFFFFFFFFF`（68719476735） |
| ECI（4G 小区编号，28 位） | 必须 > 0 且 ≤ `0xFFFFFFF`（268435455） |
| LAC + CI | LAC 在 1..65535，CI > 0 且 ≤ `0xFFFFFFFF` |
| 经纬度 + 半径 | 纬度 -90..90、经度 -180..180、不能是 (0,0)、半径 0~50000 m |
| 其它写法 | 解析不出统一编号即拦截 |

另外对“写了 ECI 却超 28 位”这种常见抄错做了专门提示：
`按 ECI 校验超出 28 位上限（最大 268435455），请核对上级原文`。

### 2. 多条参数：分别输入、逐条保存

上级经常一次给好几个目标。现在输入框下面多了「保存到目标清单」：

1. 输入一条 → 通过校验 → 点「保存到目标清单」，这条进清单、输入框清空；
2. 上级给了几条就重复几次；
3. 在「已保存的目标（N）」里点任意一条，即设为本次走测目标（单选）；
4. 每条右侧 `×` 可单条删除，标题旁「清空」一次清空。

清单存在本机（`prefs` 键 `saved_targets`，用不可见分隔符拼接，不依赖 JSON），
杀进程重进仍在。**本版一次任务仍是一个目标**：清单解决的是“多组参数逐条录入、挑一个开测”，
不是一次同时测多个基站（多目标拟合涉及覆盖算法与导出全链路，留待后续版本）。

### 3. 感叹号说明：这些参数是干嘛的

`ui\common\InfoHints.kt` 新增统一的 `HelpHint`（22 dp 圆形 ⓘ），点击弹窗，文案集中在 `HelpTexts`：

- **目标参数**怎么填：ECI / NCI / LAC+CI / 经纬度+半径各是什么、在哪抄、抄错会怎样；
- **判定阈值**怎么算信号强弱：RSRP ≥ -85 dBm 接近满格、-85~-100 正常、-100~-110 偏弱、< -110 基本脱网；
  阈值默认 -110 dBm 的来历，想更严格就推到 -100/-95；
  并解释“邻区点要单独够门槛才算数”“脱离目标的点只画轨迹不参与面积”。

### 4. 判定阈值旁的说明入口

「判定阈值」标题右侧新增 ⓘ，同时把当前值直接写在标题栏（`≥ -110 dBm 记为有效覆盖`），
不用拖动滑杆也能确认现在用的是多少。

## 二、标点（小旗）

### 1. 可见范围：全队 / 仅自己 / 指定成员

多人任务里点地图建标点时，弹窗多了「谁能看到」三选一：

| 选项 | 效果 |
| --- | --- |
| 全队可见（默认） | 所有队员的地图上都能看到 |
| 仅自己 | 只有创建者能看到；别人（包括队长）看不到 |
| 指定成员 | 只列给勾选的那几位 |

实现要点：协议 `Marker` 新增 `visibleTo: List<String>`；服务端 `RoomWs.broadcastState` 由“一份 State 广播给所有人”
改成**逐会话构造**——每个成员收到的是过滤后的标点列表
（`visibleTo.isEmpty() || m.by == uid || m.visibleTo.contains(uid)`）。
这样“仅自己可见”是真不发出去，而不是客户端假隐藏。

### 2. 命名

弹窗里可填名称（≤24 字，可空）。填了名称后：地图气泡、标点详情标题都优先显示名称，
详情里也多一行「名称」。不填仍按“普通旗标 / 可疑设备标点”显示。

### 3. 删除

- 单人模式：点自己的标点 → 详情左下「删除」。
- 多人模式：标点详情左下「删除」→ 发 `markerDelete` 协议消息；服务端权限是**本人或队长**
  （`it.by == msg.by || isCaptain`），普通队员删不掉别人的点。

## 三、热力图参数说明

图层面板开启「信号热力图」后，滑杆区上方多了「热力图参数」标题与 ⓘ，逐条解释：

- **热力图是什么**：把一路测来的信号强度按位置铺成彩色底图，一眼看出好区和盲区；
- **配色**：青绿=强、黄=中、橙红=弱，颜色由两条阈值线算出来，不是固定色；
- **网格间隔**：15 m 适合小区街巷细看，50 m 适合大范围快速看，调小更细腻但更吃内存；
- **扩散半径**：每个实测点向外晕开多远，越大越连贯、越小越贴近原始点位；
- **透明度**：盖在地图上的浓淡，太浓挡路名；
- **强 / 弱信号阈值**：两条线怎么定强度分界。

## 四、静默跟踪：振动逻辑与强度

### 1. 振动逻辑说明（工具箱标题旁 ⓘ）

- 跑测时不开屏、不看地图、手机揣兜里，靠震动判断“现在有没有盯着目标基站”；
- **主区命中**（手机挂在目标小区上）：每 1 秒短震一次，节奏稳，像心跳；
- **邻区命中**（看得到目标但没连上）：每 0.3 秒急促短震，提示快到边界了；
- **完全脱离**：一直震动不停，直到走回去或手动关掉；
- 全程只震动——不出声、不弹窗、不点亮屏幕；通知栏有一条常驻通知用来「停止」并防系统杀进程；
- 费电说明：后台持续读基站 + 震动，比平时费电，长时间用带充电宝，测完记得关；
- 三个停止入口：工具箱开关 / 通知栏「停止」/ 地图底部状态条。

### 2. 振动强度可调 1~5 档

静默跟踪打开后，工具箱多一行「震动强度」滑杆（轻 / 较轻 / 中 / 较强 / 强），
映射振幅 60 / 110 / 160 / 205 / 255，写 `prefs` 键 `silent_strength`，重启后保持。

实现坑（留给后续维护）：连续震动的波形必须是
`VibrationEffect.createWaveform(longArrayOf(0, pulseMs, 200), intArrayOf(0, amplitude, 0), 0)`——
振幅要传 `IntArray`，传单个 `Int` 会编译失败或退化成默认强度。

## 八、已知限制

1. 一次任务仍只对应一个目标小区；目标清单是“多组参数挑一个”，不是“一次同时测多个”。
2. 说明书是静态文案，阈值/参数改了不会跟着变（除判定阈值标题栏的当前值）。
3. “仅自己可见”仅在多人协同房间内生效；单人模式的标点本来只有本机数据。
4. 振动强度受手机振动马达限制，部分机型 1~2 档几乎感觉不到。
