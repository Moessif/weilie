# v0.13.8：图层抽屉适配 + 首页副标题处理

## 一、图层抽屉适配（主要）
v0.13.6 把图层面板改成了底部抽屉，但面板组件仍带「浮层模式」的排版：
顶部 52dp 留白、宽度只有屏宽 82%，放进抽屉后出现大块空白与错位。

改动：
- `MapLayersPanel` 新增 `inSheet: Boolean = false`
  - `inSheet=true`：去掉顶部留白、宽度撑满、不注册「点空白关闭」；
  - `inSheet=false`：保持原浮层行为（兼容其它调用点）。
- `SingleMapScreen` 调用抽屉时传 `inSheet = true`。

效果（320×568dp）：标题「地图图层」紧贴拖拽条下方，选项撑满抽屉宽度，
列表可滚动，无空白、无重叠。

## 二、首页副标题
- 「逐秒采样 · GPS 双重安检 · 自动拟合覆盖范围」改为单行省略后，在 320dp 下仍会
  从页头下方露出一截并被统计卡压住；
- 该行与状态行「待机中 · 尚未开始采集」信息重复，**直接移除**，同时给滚动区加 `clipToBounds()`。

## 四、已知遗留
320dp 下向上滚动首页时，雷达区底部的「待机中 · 尚未开始采集」会与统计卡边缘轻微重叠。
这是 RadarPanel 的高度与其下方卡片之间的排版问题（非本次改动引入），
需要把 RadarPanel 的高度改为 wrapContent 或把统计卡并入同一滚动列后再修。
